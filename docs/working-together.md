# 日常怎样一起工作

## 一项社区工作

提出问题 → 说明产出与参考资料 → 确认接待和评审 → 认领 → 提交 → 反馈 → 继续、交接或结束。

每项工作有一个主要 Issue。状态可分为待确认、可认领、进行中、待反馈、已完成和暂缓。看板引用原事项，不再复制一份待办。

认领时约定下一次检查时间；有变化及时调整范围、时间或交接方式。完成时留下成果链接与评审意见。

## 信息如何保留

群里可以交流。形成需要继续推进的任务、决定或可复用知识后，由相关责任人把简短结论回写到原事项或文档。

问答先留在讨论区，反复出现的问题整理成 FAQ。文件修改走 PR；同一个决定不在多个位置反复维护。

## 拟议维护节奏

| 频次 | 要做什么 | 留下什么 |
|---|---|---|
| 每周一次异步整理 | 看新问题、等待项、任务和到期资源 | 更新原事项与必要目录 |
| 每月一次社区更新 | 汇总实际成果、贡献和缺口 | 简短更新与链接 |
| 有需要再开讨论会 | 处理跨角色分歧、答疑或分享 | 结论和下一步 |
| 人员职责变化时 | 核对接待、权限与交接 | 更新维护分工 |

以上频次由实际承担者确认后启用。自动欢迎语不代替人工接待；没有人接手时，明确当前等待的条件。
