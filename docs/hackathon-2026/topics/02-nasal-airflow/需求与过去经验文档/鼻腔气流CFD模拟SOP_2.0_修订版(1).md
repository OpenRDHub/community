# **1. 预备知识与整体流程**

## **1.1 这套流程在做什么**

我们要把一个人的 CT 扫描数据，变成可以“看见空气如何在鼻腔里流动”的三维模拟。整个过程分五步：

1. 拿到 CT 数据（DICOM 文件）
2. 把鼻腔气道的空间形状抠出来（分割 → 得到 STL 三维模型）
3. 修补这个三维模型的破洞（几何修复）
4. 让计算机算出空气怎么流（CFD 求解）
5. 把计算结果画成图（可视化分析）

## **1.2 你需要多少基础**

- 阶段一至三、阶段五：会用电脑、能跟着截图操作即可，**无需编程**。
- 阶段四的 SimScale 方案：网页操作，**无需编程**。
- 阶段四B的 OpenFOAM 进阶替代方案：需要 Linux/命令行基础，初学者可跳过。

## **1.3 大约需要多长时间**

| **阶段** | **首次操作耗时（含学习）** | **熟练后** |
|-|-|-|
| 分割 | 30 分钟 | 10 分钟 |
| 修复 | 2–4 小时 | 30–60 分钟 |
| 求解(SimScale) | 设置30分钟+计算1–4小时 | 同左 |
| 可视化 | 1–2 小时 | 30 分钟 |

# **3. 阶段一：获取与检查 CT 源文件**

## **3.1 从哪里拿 CT 数据**

1. 到做检查的医院影像科（放射科），申请刻录原始 DICOM 数据光盘或拷贝到 U 盘。
2. 明确告诉对方你要的是 DICOM 原始数据（.dcm 文件），不是打印胶片，也不是导出的 JPG 图片。
3. 取得的文件通常是一个文件夹，里面有几十到几百个 .dcm 文件。

## **3.2 对 CT 质量的要求（关键）**

| **参数** | **要求** | **说明** |
|-|-|-|
| 层厚 | ≤ 1mm，推荐 0.5mm | 越薄，鼻腔细节越清晰 |
| 重建算法 | 骨算法 / 高分辨率 | 鼻腔骨壁边界更锐利 |
| 扫描范围 | 覆盖鼻尖到鼻咽 | 气道必须完整 |
| 是否增强 | 平扫即可 | 不需要打造影剂 |

*提示：若手头 CT 层厚是 3mm 或 5mm，也能勉强做，但鼻腔细节会丢失很多。条件允许时建议专门做一次薄层鼻窦 CT。*

## **3.3 隐私须知（务必执行）**

DICOM 文件里嵌有患者姓名、出生日期、病历号等个人信息。在上传到任何云端平台前，必须先做去隐私化（匿名化）：

- 3D Slicer 自带匿名工具：DICOM 模块中有 Anonymize（匿名化）功能。
- 或只导出分割后的 STL 文件上传云端——STL 是纯几何模型，不含任何个人信息，这是最安全的做法。

## **3.4 检查清单**

- 拿到的是 .dcm 文件而非图片
- 层厚 ≤ 1mm
- 扫描范围覆盖完整鼻腔
- 已规划好匿名化方案

# **4. 阶段二：三维气道分割（3D Slicer）**

*这是整个流程最关键的一步，通常耗时较短。目标：把鼻腔里“空气所在的空间”提取成一个三维模型。后续 STL 几何修复通常是耗时最长的环节。*

## **4.1 导入 CT 数据**

1. 打开 3D Slicer。
2. 点击左上角 DCM（或菜单 File → Add DICOM Data）。
3. 在 DICOM Browser 中点击 Import DICOM files，选择你的 CT 文件夹。
4. 导入后选中序列 → 点 Load。
5. 加载成功后主界面会显示三个切面视图（红=轴位、黄=矢状、绿=冠状）。

## **4.2 切换到 Segment Editor（分割编辑器）**

1. 在顶部模块下拉菜单中选择 Segment Editor（可在搜索框输入快速定位）。
2. 点击 + Add 新建一个 Segment，双击重命名为 Airway（气道）。

## **4.3 用阈值工具初步提取气道**

空气在 CT 上的 HU 值很低（接近 -1000）。我们用阈值把低密度空气区域圈出来。

1. 在工具列表中点击 Threshold（阈值）。
2. 设置阈值范围：下限约 -1024，上限约 -300（可微调，目标是让鼻腔气道恰好被高亮，有技术说是400，具体情况根据具体情况分析。）。
3. 点击 Apply。此时所有符合该 HU 范围的区域都会被标记。

## **4.4 关键：分离出“只要的”鼻腔气道**

阈值会把所有空气都圈进来，但我们只要从鼻孔到鼻咽的主气道。

**方法 A — 用 Islands（孤岛）工具保留连通区域：**

- 先用 Scissors（剪刀）或 Erase（橡皮擦）切断鼻孔处的部分体积，切除很薄的一部分就行，不要影响鼻孔内气道体积（目的是切断鼻腔内部和外部的气道连续性，方便后续删除鼻腔外部空气）。
- 点击 Islands 工具，选择 Keep selected island（保留选中孤岛）
- 在视图中点击鼻腔主气道区域，只保留与点击点连通的那块。

**方法 B — 手动逐层修正（最可靠）：**

- 使用 Paint（画笔）添加遗漏的气道。
- 使用 Erase（橡皮擦）擦掉不要的鼻窦、外部空气。
- 逐层检查：在红/黄/绿三个视图中滚动，确保每层气道边界都正确。

*ENS 患者特别注意：下鼻甲被切除后鼻腔异常宽大，阈值分割时边界判断困难，需格外仔细地逐层手动修正，必要时对照解剖图谱。*

## **4.5 设定进出口边界**

- 鼻孔处气道有清晰开口平面（不要封死）。
- 鼻咽末端用 Scissors 沿冠状面切一刀，形成平整出口。

## **4.6 生成三维模型并导出 STL**

1. 点击 Show 3D 按钮，预览气道立体模型，旋转检查是否有破洞、毛刺、断裂。
2. 切换到 Segmentations（分割集合）模块。
3. 找到 Export to files：格式选 STL，选择保存路径，点击 Export。
4. 得到 Airway.stl 文件——这就是鼻腔气道的三维几何模型。

## **4.7 阶段二检查清单**

- 气道从鼻孔到鼻咽完整连通
- 鼻窦旁路、外部空气已剔除
- 三维预览无明显破洞/断裂
- 已导出 .stl 文件

# **5. 阶段三：STL 几何修复（Blender）**

*说明：以下 Blender 菜单路径按常见版本整理；不同软件版本或界面语言可能略有差异，请以当前版本中的对应功能为准。*

## **5.1 导入 STL 到 Blender**

- 打开 Blender → File → Import → STL → 选择 Airway.stl。

## **5.2 简化网格（目的是降低模型面数，加快气流模拟，在不影响气流模拟效果的情况下执行简化）**

- 修改器选择精简，模式为塌陷，比率设置为30-50%即可，不要降低太多，可能会导致模型出现点线面问题，测试过程中目标面数设 > 3万。

## **5.3 修复流程（目的是修复简化网格过程中出现的点线面问题，如未简化无需执行此步）**

启用检测插件：Edit → Preferences → Add-ons，搜索并启用 3D Print Toolbox；随后在 3D 视口侧栏使用 Check All 检查非流形、交叉面等问题。

**第一步：清理重复与无效数据（Edit Mode 编辑模式）：**

- 全选网格（A）→ Mesh → Clean Up → Merge by Distance（合并重复顶点）。
- Mesh → Clean Up → Degenerate Dissolve（清除退化边和零面积面）。
- Mesh → Clean Up → Delete Loose（删除未连接的游离点、线、面）。

**第二步：检查并统一法向：**

- 全选网格（A）→ Mesh → Normals → Recalculate Outside（统一面向外侧的法向）。

## **5.4 导出修复后的 STL**

- File → Export → STL → 命名为 Airway_clean.stl → 保存。

## **5.5 阶段三检查清单**

- 已删除重复/无效面
- 法向已统一
- 文件大小适中（建议 3 万–10 万面）
- 鼻孔入口与鼻咽出口开口均已保留
- 已导出 Airway_clean.stl

# **6. 阶段四：CFD 求解（SimScale 云端方案 · 推荐）**

SimScale 把网格划分和求解都封装在网页里，无需安装、无需编程，是入门首选。

## **6.1 创建项目并上传模型**

1. 登录 simscale.com。
2. 点击 Create Project，填写项目名（勿含患者姓名）。
3. 点击 Geometry → Import/Upload，上传 Airway_clean.stl。
4. 在三维视图中检查模型是否完整显示。



- 预处理模型：

1. 上传模型后，在模型鼻孔处和鼻咽部各添加一个圆柱体，用于延长入口/出口流体区域，使边界条件远离鼻腔复杂几何；该操作不改变鼻腔原有结构。
2. 使用 Union 工具将 2 个圆柱体与气道模型进行并集。
3. 确认并集后的几何完整，再开始模拟。

## **6.2 选择分析类型**

- 点击 Create Simulation，分析类型选 Incompressible（不可压缩流）——鼻腔气流速度远低于声速。

## **6.3 设置流体材料**

- 在 Materials 中添加 Air（空气），使用默认空气物性即可（密度约 1.2 kg/m³，黏度约 1.8×10⁻⁵ Pa·s）。

## **6.4 设置边界条件（核心）**

| **边界** | **类型** | **设置** |
|-|-|-|
| 鼻孔处圆柱体截面（入口） | Velocity / Pressure inlet | 静息呼吸：约 15 L/min（单侧约 7.5）  <br/>如选择Pressure inlet则设置参数为-18pa |
| 鼻咽处圆柱体截面（出口） | Pressure outlet | 压力设为 0（相对大气压） |
| 鼻腔壁面 | Wall（无滑移） | No-slip（默认） |

如何指定面：在三维视图中点选 STL 上的鼻孔开口面、鼻咽开口面，分别赋予 inlet/outlet 类型；其余表面默认为 wall。

关于流量：成年人静息经鼻气流约 15 L/min（双侧合计）。只模拟单侧时取一半。吸气与呼气可分别设置方向。

## **6.5 选择湍流模型**

- 鼻腔静息气流雷诺数约 1000–2500，处于层流到过渡流区间。
- 入门先选 Laminar（层流）跑通流程。
- 科研定量分析推荐使用 k-omega SST 湍流模型，适合过渡流与中等流速；入门验证流程时可先用 Laminar。

## **6.6 生成网格**

1. 进入 Mesh 设置，选择自动网格，精度先选 Moderate（中等）。
2. 点击 Generate Mesh，等待云端计算（约 10–40 分钟）。
3. 检查网格质量报告，单元数建议在 30 万–200 万之间。

## **6.7 运行求解**

1. 进入 Simulation Control，设置迭代步数（如 1000 步）。
2. 点击 Start Simulation。
3. 云端排队+计算通常 1–4 小时。在 Convergence Plot 查看残差是否下降并趋于平稳——残差平稳即收敛。

## **6.8 下载结果**

- 完成后可在网页内用 Post-processing 查看，或 Download 下载结果文件（VTK 格式），用于阶段五本地深入分析。

## **6.9 阶段四检查清单**

- STL 已上传且显示完整
- 分析类型 = Incompressible
- 入口/出口/壁面边界已正确指定
- 流量/压力数值已设置
- 湍流模型已选择
- 网格生成成功、质量合格
- 残差收敛
- 结果已查看/下载

# **7. 阶段四B（进阶替代方案）：CFD 求解（OpenFOAM 本地方案）**

*本节面向有 Linux/命令行基础的成员，初学者可跳过，先用 SimScale。*

## **7.1 准备工作**

- 安装 OpenFOAM（推荐 Ubuntu/Linux，或 Windows 用 WSL2）。
- 准备算例目录结构：0/（初始与边界条件）、constant/（物性、网格）、system/（控制、网格划分、求解设置）。

## **7.2 网格划分流程**

1. 把 Airway_clean.stl 放入 constant/triSurface/ 目录。
2. 编辑 system/blockMeshDict：定义包含整个鼻腔的长方体背景网格。
3. 运行 blockMesh 生成背景网格。
4. 编辑 system/snappyHexMeshDict：指定 STL 表面、加密层级、边界面命名（inlet/outlet/wall）。
5. 运行 snappyHexMesh -overwrite 将网格贴合到鼻腔几何。
6. 运行 checkMesh 检查网格质量（关注 non-orthogonality、skewness）。

## **7.3 设置边界条件**

- 0/U（速度场）：inlet 给定速度或流量，outlet 设 zeroGradient，wall 设 noSlip。
- 0/p（压力场）：outlet 设固定值 0，inlet 与 wall 设 zeroGradient。
- 若用湍流模型，还需设置 k、omega 等场文件。

## **7.4 选择求解器并运行**

- 稳态层流/湍流常用 simpleFoam。
- 在算例目录运行 simpleFoam（或后台 simpleFoam > log &），监控 log 中残差是否收敛。

## **7.5 转换结果供查看**

- 运行 paraFoam 直接打开，或运行 foamToVTK 转成 VTK 文件供 ParaView 读取。

# **8. 阶段五：结果可视化与分析（ParaView）**

## **8.1 打开结果**

1. 打开 ParaView → File → Open，选择结果文件（SimScale 的 VTK，或 OpenFOAM 的 .foam / VTK 文件）。
2. 点击左侧 Apply 加载。

## **8.2 常用可视化视图**

**(1) 速度云图（Velocity Contour）**

- 在 Coloring 下拉中选择 U（速度），即可看到鼻腔内各处速度的颜色分布（红=快，蓝=慢）。

**(2) 流线图（Streamlines）**

- Filters → Common → Stream Tracer，设置种子点在鼻孔入口，Apply 即可看到气流路径。

**(3) 截面切片（Slice）**

- Filters → Common → Slice，沿冠状面/矢状面切一刀，查看该截面速度/压力分布。

**(4) 压力分布（Pressure）**

- 在 Coloring 中选择 p（压力），查看从鼻孔到鼻咽的压力降。

## **8.3 量化关键数据**

- 鼻阻力：入口与出口的压力差 ÷ 流量，是临床衡量鼻腔通气功能的核心指标。
- 壁面剪切应力：反映气流对黏膜的刺激强度，对 ENS 研究尤为重要。
- 用 Filters → Data Analysis → Integrate Variables 在某个面上积分求平均值。

# **9. ENS 专用分析指标**

对空鼻综合征研究而言，比“气流快慢”更有意义的是以下指标。建议每个病例都重点考察。

## **9.1 气流分布均匀性**

ENS 患者因鼻甲缺失，气流往往集中在某一通道（如底部），原本鼻甲所在的中上部成为低速“死区”。在冠状切片上观察速度分布是否异常集中或出现大片低速区。

## **9.2 鼻甲区低速死区**

重点观察原下鼻甲/中鼻甲所在区域的气流速度。速度过低意味着该区域黏膜几乎接触不到流动气流——这与 ENS 患者“感觉不到呼吸”的主诉高度相关。

## **9.3 黏膜壁面剪切应力**

鼻黏膜上的气流感受器依赖气流的机械刺激产生“通畅感”。剪切应力过低 → 感受器刺激不足 → 主观憋气感。对比 ENS 鼻腔与正常鼻腔的壁面剪切应力分布，是解释症状的关键证据。

## **9.4 温湿度交换（进阶）**

鼻腔的核心功能之一是加温加湿。进阶模拟可加入热/质传递，评估气流经过鼻腔后温度、湿度的变化效率，量化 ENS 患者的功能损失。

## **9.5 指导鼻腔衬片设计**

上述指标共同回答一个问题：怎样的鼻腔形态能恢复正常的气流分布与黏膜刺激？通过反复修改 STL 几何（模拟加装衬片）、重跑 CFD、对比指标，即可反向推导出最优的鼻腔衬片（nasal insert）形状——这正是 K-Hub“CT → 气流建模 → 鼻腔衬片设计”框架的技术闭环。

# **10. 常见问题排查（FAQ）**

**Q1：分割时鼻腔和外部空气连在一起分不开？**

在鼻孔平面用 Scissors 或 Erase 切断连接处，再用 Islands 工具保留鼻腔主体。

**Q2：Blender 修复时把鼻孔/鼻咽出入口也封死了？**

在 Blender 中封洞前先确认开口尺寸；只修补内部小洞，保留鼻孔和鼻咽出入口。若已封死，可在 CFD 软件中重新定义开口面。

**Q3：SimScale 网格生成一直失败？**

多半是 STL 几何有自相交或破洞。回到 Blender 重新清理、检查法向并修补内部小洞，注意保留入口/出口开口；或降低网格精度先跑通。

**Q4：求解残差不下降/不收敛？**

降低网格精度先验证流程；检查边界条件是否合理；层流不收敛时尝试 k-ω SST；增加迭代步数。

**Q5：SimScale 免费配额用完了？**

降低网格精度节省算力，或转向本地 OpenFOAM 方案（完全免费、无配额限制）。

**Q6：CT 层厚是 5mm，能用吗？**

能跑但细节大量丢失，结果仅供参考。强烈建议重新做一次薄层（≤1mm）鼻窦 CT。
