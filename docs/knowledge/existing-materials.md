# 已有资料入口

先把已存在的资料连起来，再决定哪些内容值得整理到 community。

| 资料 | 现有位置 | 本轮如何使用 |
|---|---|---|
| 组织介绍、项目与共建方式 | [OpenRDHub 组织 README](https://github.com/OpenRDHub/.github/blob/main/profile/README.md) | 主页改版以它为底稿，保留品牌与项目内容 |
| 黑客松筹备、执行、复盘和交接资料 | [罕见病基因黑客松 SOP](https://github.com/OpenRDHub/rare-disease-gene-hackathon-sop) | community 先做索引，专项手册仍在原仓库维护 |
| 现有需求登记 | [rare-disease-list Issues](https://github.com/Khub-OpenRD/rare-disease-list/issues) | 暂时保留原入口，讨论迁移时给出明确去向 |
| 社区协作平台 | [OpenRD-CollabPlat](https://github.com/OpenRDHub/OpenRD-CollabPlat) | 保留已有平台，资料网页的首版不依赖改造它 |
