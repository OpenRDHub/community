# 白化病辅助器具：深度产品分析

> 三个核心问题：
> 1. 我们到底需要什么？
> 2. 目前有什么？
> 3. 我们能做什么？
>
> 分析日期：2026-08-24
> 分析视角：产品经理视角，不谈技术谈价值
>
> **已知约束**：
> - 目标用户：全覆盖（所有年龄段）
> - 商业模式：公益 + 残联采购支付
> - 核心需求：放大，且现有辅具放大倍数不够

---

## 一、先说一个反直觉的结论

现有辅具市场研究了17款产品，结论不是"功能不够"，而是**方向错了**。

所有辅具厂商在做的事：**让用户"看得见"**。

白化病人真正需要的：**让自己"做得到"**。

这两个的区别是什么？

张艺瑄视力不足0.01，用望远镜能看见黑板上的字——但他上课仍然很累，因为他一边举着望远镜，一边记笔记，同时还要听老师讲，三件事全靠一个大脑。

高瑞敏视力0.01，同桌念一句她写一句——字她看见了，但她**读不出**，因为她的视网膜根本处理不了文字信息。

所以：

- 手持电子助视器解决的是"看见"的问题，但仍然需要**占一只手**
- AR眼镜解决的是"看见+不占手"，但仍然需要**自己读**
- OCR朗读解决的才是"读不出"的问题，但**只有一款有，还离线要4000起**

**核心洞察：市场上没有人在解决"读不出"的问题。**

放大镜、AR眼镜、光学助视器——它们都在帮用户"看见"。但看见不等于理解。把文字放大10倍，白化病人仍然看不清。把文字念出来，他立刻懂了。

这不是辅具的技术问题，这是对用户需求的根本性误判。

## 二、已知约束：商业模式决定一切

用户已明确两个约束条件，这彻底改变了分析方向：

### 2.1 约束1：目标用户 = 全覆盖

这意味着产品必须满足**所有年龄段**的需求，不能只做某一类用户：

| 用户群 | 核心场景 | 主要需求 |
|--------|---------|---------|
| 儿童（6-12岁） | 上课看黑板、看书 | 放大 + 近处OCR + 家长端监控 |
| 青少年（13-18岁） | 课堂学习、考试 | OCR朗读 + 远距离放大 + 解放双手 |
| 大学生（18-22岁） | 自主学习、社交 | OCR朗读 + 人脸识别 + 障碍物警报 |
| 成年人（22-50岁） | 工作、出行 | 障碍物警报 + 人脸识别 + 近处OCR |
| 老年人（50岁+） | 日常生活 | 放大 + 物品识别 + 障碍物警报 |

**结论**：产品功能必须覆盖"学习 + 出行 + 社交"三大场景，不能只做某一个。

### 2.2 约束2：商业模式 = 公益 + 残联采购

残联采购的本质是什么？

```
政府采购 = 功能清单 + 价格 + 资质
```

残联评估辅具的核心指标：
1. **放大倍数够不够高**（最核心指标）
2. **显示够不够清晰**
3. **价格够不够低**
4. **是否有医疗器械资质**
5. **是否在采购目录内**

这意味着：
- 产品必须进**辅具采购目录**
- 可能需要**医疗器械认证**（NMPA/FDA）
- **价格敏感**（残联预算有限）

### 2.3 约束3：放大是核心，且现有放大不够

用户明确说"放大倍数可能有问题"，这是关键约束。

现有辅具的放大能力：

| 产品 | 最大放大 | 价格 | 残联采购评估 |
|------|---------|------|-------------|
| OCUTECH Sport II | 6x | ¥5,000-8,000 | 放大不够，PASS |
| 12寸斯诺 | 19x | ¥4,000-6,000 | 放大中等，桌面形态限制 |
| CloverBook Plus | **60x** | ¥6,000-10,000 | 放大最高，但价格高 |
| Acesight AR | 15x | ¥10,000-20,000 | 放大中等，价格太贵 |

**残联的问题：要么放大不够（OCUTECH），要么太贵（CloverBook Plus），要么形态不适合日常使用（12寸斯诺）。三者不可兼得。**

## 三、我们到底需要什么

### 3.1 需求分层：五个层次，不是平等并列

把所有需求按依赖关系分层：

```
第四层（可选）  │  物品识别、条码扫描、颜色识别
第三层（重要）  │  人脸识别播报、场景描述
第二层（核心）  │  OCR朗读、障碍物警报
第一层（基础）  │  文字放大、色彩增强、冻屏
底层（前提）    │  解放双手、不依赖他人
```

**底层比第二层重要，第二层比第三层重要。**

为什么这么说？

看高瑞敏的例子。她0.01视力，同桌念一句她写一句。她的需求优先级：

1. **最底层**：不用求同桌 → 这件事让她最痛苦，最伤害自尊
2. **第二层**：有人给她念 → 这是她上课学习的唯一方式
3. **第三层**：放大书本 → 这个她已经放弃了（脸贴到纸面上也没用）

而现有辅具全部在解决第三层及以上（放大书本、色彩增强、冻屏），没有人解决底层和第二层。

### 3.2 三个真实场景的精确需求拆解

#### 场景A：上课（最高频、最重要）

```
徐苛苹的一天：
07:30 早读 ── 望远镜举着看课本（一只手占着）
08:00 第一节课 ── 望远镜举着看黑板（举了40分钟）
08:45 第二节课 ── 望远镜举着看黑板（手开始酸）
09:30 第三节课 ── 手已经酸得举不动了
10:00 做笔记 ── 望远镜放下，脸埋进纸面2cm写字
```

她需要的不是放大，是**朗读**。

AR眼镜能不能解决？理论上能。但现有AR眼镜的逻辑是"把画面放大显示在眼前"。这解决的是张艺瑄的问题（他看得见，只是不方便），解决不了徐苛苹的问题（她看不清，需要念给她听）。

**精确需求**：摄像头对准黑板 → 实时OCR → 语音朗读 → 跟上老师讲课速度

这个需求，17款辅具里只有一款（瑞杰珑12寸斯诺）能做到离线版本，还只能手持/桌面用。

#### 场景B：出行（最低保障需求）

```
高瑞敏的一天：
出行 ── 畏光，室外眯着眼睛走
过马路 ── 靠听声音判断
室内 ── 勉强能看见大轮廓
暗处 ── 几乎什么都看不见
```

0.01视力的人，出行就是冒险。

但这个问题在辅具市场几乎被忽略了。OCUTECH SideSight是唯一一款障碍物检测产品——但它是给偏盲患者用的（半边视野缺损），不是给白化病用的。白化病的视力问题是"全面模糊"，不是"半边视野缺损"。

**精确需求**：前方障碍物检测 → 距离播报 → 在撞上前预警

这个需求，所有辅具都没有针对性的解决方案。

#### 场景C：社交（被忽视的需求）

```
高瑞敏在路上遇到同学 ──
她看不清对方的脸，但能听出是谁
她热情地打招呼，但心里不确定是不是认错了人

张艺瑄去面试 ──
HR问："你对我们公司有什么了解？"
他看不清HR的脸，记不住这是谁
面试结束后，他甚至不知道面试官长什么样
```

"看不清人脸"不只是看不清，更是一种**社交上的不确定性**。

这个需求没有任何辅具在解决。Seeing AI有人脸识别功能，但在眼镜上使用时，用户体验完全未知。

**精确需求**：识别熟人 → 播报姓名 → 识别表情（可选）

### 3.3 需求优先级总结（考虑残联采购）

| 优先级 | 需求 | 为什么排这个顺序 | 现有辅具解决程度 | 残联采购权重 |
|--------|------|----------------|----------------|-------------|
| 🥇1 | **放大** | 残联核心指标，必须够用 | 部分解决，但不够/太贵/形态差 | ⭐⭐⭐⭐⭐ |
| 🥈2 | OCR朗读 | 上课是一切的前提，读不出字一切免谈 | 仅1款（¥4000+，还离线） | ⭐⭐⭐⭐ |
| 🥉3 | 解放双手 | 举望远镜上课是对身体的慢性伤害 | AR眼镜有，但¥10000+ | ⭐⭐⭐ |
| 4 | 障碍物警报 | 安全出行的最低保障 | 0（SideSight是偏盲专用） | ⭐⭐⭐ |
| 5 | 人脸识别 | 社交尊严，被完全忽视 | 0 | ⭐⭐ |

## 四、目前有什么

### 4.1 辅具市场的真实格局

经过对17款辅具的系统分析，辅具市场呈现三个特征：

#### 特征1：价格与功能严重不匹配

```
¥0     : Seeing AI（功能最完整的中文OCR）
¥699   : 展迈M1（手机+VR眼镜，联网OCR）
¥3000  : Luna 8（无OCR，只有放大）
¥4000  : 12寸斯诺（唯一离线OCR，但桌面形态）
¥5000+ : OCUTECH全系列（无OCR，只有光学放大）
¥10000+: Acesight AR（无OCR，只有放大）
¥15000+: Acesight VR（无OCR，只有放大）
```

结论：**价格和OCR能力完全无关。贵的反而没有OCR。** ¥15000的VR眼镜能放大16倍，但没办法把黑板上的字念出来。¥0的Seeing AI可以。

#### 特征2：市场在做"放大"，用户在等"朗读"

17款辅具的功能方向：

| 功能方向 | 产品数量 | 说明 |
|---------|---------|------|
| 纯光学放大 | 8款 | OCUTECH全部 + 翠鸟Aeye-T04 |
| 电子放大+色彩 | 5款 | Luna 8、Clover系列、部分Acesight |
| OCR朗读 | 2款 | 12寸斯诺（离线）、璧羽（联网） |
| AI功能 | 1款 | 天使眼（物品识别，¥3800） |
| 障碍物警报 | 1款 | SideSight（偏盲专用） |

**76%的辅具在解决"放大"问题，只有12%在尝试OCR，且其中一半还依赖网络。**

市场花了几十年把放大功能做到极致（19倍、23倍、60倍），但用户最需要的恰恰是放大之外的东西。

#### 特征3：技术代差至少5年

| 功能 | 消费级AI已实现 | 辅具行业现状 |
|------|---------------|------------|
| 中文OCR+离线朗读 | ✅ Seeing AI免费 | ❌ 辅具只有1款（¥4000） |
| 实时人脸识别+姓名 | ✅ Seeing AI免费 | ❌ 辅具全部缺失 |
| 物品识别 | ✅ 多个免费APP | ❌ 辅具只有1款（¥3800） |
| 障碍物检测 | ✅ 手机AR应用 | ❌ 辅具全部缺失 |
| 场景描述（AI读图） | ✅ Seeing AI部分 | ❌ 辅具全部缺失 |

**辅具行业的技术水平，相当于消费级AI应用2018年的水平。** 这个差距不是技术问题，是行业惯性——辅具厂商在卖硬件赚利润，没有动力做软件AI升级。

### 4.2 翠鸟视觉产品深度解读（重要竞品）

翠鸟是Dream Glass 4K最直接的竞争对手，需要深入分析。

#### 翠鸟产品线概览

翠鸟有4款产品，分两条完全不同的技术路线：

| 产品 | 技术路线 | 定位 | 核心问题 |
|------|---------|------|---------|
| **璧羽** | AR+Android | 头戴式旗舰 | OCR要联网 |
| **Aeye-X R4s** | AR+Android | 头戴式高清 | 仅苹果投屏 |
| **Aeye-P4** | 便携触屏 | 台式替代 | OCR要联网 |
| **Aeye-T 04** | 纯光学眼镜 | 轻便户外 | 无任何电子功能 |

---

#### 产品1：璧羽（2020年，AR头戴旗舰）

```
定位：全球第二款AR低视力助视器
价格：未公开（估计¥8,000-15,000）
核心卖点：Android系统 + AR显示 + 1-20x放大
```

**参数亮点**：
- 骁龙835处理器（当时的旗舰手机芯片）
- 800万单摄像头
- 1-20倍放大
- PIP画中画（看远处的同时保留近处画面）
- 冻屏功能
- 蓝牙遥控

**致命问题：OCR需要联网**

这意味着：
- 上课看黑板 → 学生周边没有WiFi → OCR失效
- 户外走路 → 移动网络信号差 → OCR失效
- 考试 → 绝对没有网络 → 完全没用

**次要问题：重量较重，未成年人不适用**

璧羽的定位是"户外AR眼镜"，但白化病低视力人群中，未成年人（小学/初中/高中）恰恰是核心用户群——他们每天上课最需要助视器。结果璧羽对这部分用户直接关闭了大门。

**一句话总结**：璧羽是一个"联网时很强，断网时废掉"的眼镜。对白化病核心用户（学生）几乎不适用。

---

#### 产品2：翠鸟慧眼Aeye-P4（2021年，便携台式）

```
定位：桌面电子助视器的便携替代
价格：未公开（估计¥6,000-10,000）
核心卖点：10英寸防蓝光屏 + 20x放大 + 1300万摄像头
```

**参数亮点**：
- 10英寸防蓝光触摸屏
- 1300万+长焦双摄（近远两用）
- 16种色彩模式
- 冻屏+阅读辅助线+遮屏
- 书写对焦锁定

**和竞品对比**：

| 参数 | Aeye-P4 | 瑞杰珑12寸斯诺 | 度康CloverBook Plus |
|------|---------|--------------|-------------------|
| 屏幕 | 10寸 | 12寸 | 12.5寸 |
| 放大 | 20x | 19x | **60x** |
| OCR | ⚠️需联网 | ✅离线 | ❌ |
| TTS | ❌ | ✅离线 | ❌ |
| 价格 | 未公开 | ¥4,000-6,000 | ¥6,000-10,000 |

**致命问题：OCR要联网 + 无TTS**

Aeye-P4的价格和12寸斯诺差不多，但：
- 12寸斯诺有**离线OCR+离线TTS**（完全不需要网络）
- Aeye-P4的OCR**需要联网**（等于没用）

这让Aeye-P4在核心功能（OCR朗读）上完全输给12寸斯诺。

**一句话总结**：Aeye-P4是一个"屏幕比斯诺小、放大比斯诺低、OCR比斯诺差、价格估计比斯诺贵"的产品。定位尴尬。

---

#### 产品3：翠鸟Aeye-X R4s（2022年，AR头戴最新）

```
定位：目前翠鸟最高端AR眼镜
价格：未公开（估计¥8,000-15,000）
核心卖点：53° FOV（AR中最大）+ 离线OCR + TOF深感
```

**参数亮点**：
- **双1300万+TOF深感摄像头**（AR中最高配置）
- **53°视场角**（AR助视器中最大，视野更宽）
- 陀螺仪六轴定位（画面稳定）
- **离线OCR**（唯一一个不需要联网的翠鸟产品）
- 高清放大显示
- 冻屏+色彩增强+描边

**和璧羽的关键区别**：

| 参数 | 璧羽 | Aeye-X R4s |
|------|------|-----------|
| 摄像头 | 800万单摄 | **双1300万+TOF** |
| FOV | 未公开 | **53°最大** |
| OCR | ⚠️需联网 | ✅**离线** |
| 近远切换 | 手动 | **TOF自动** |
| 投屏 | 未说明 | **仅Mac/iOS** |

**致命问题：仅支持苹果Mac/iOS投屏**

这是Aeye-X R4s最诡异的设计：
- 它有离线OCR → 可以识别文字
- 但识别后的文字**只能投屏到Mac或iOS设备上显示**
- Windows/Android用户直接不能用

这等于：
- 学生用的是Windows笔记本 → 投屏不了 → OCR白搭
- 用户用的是华为/小米/OPPO手机 → 投屏不了 → OCR白搭
- 只有苹果全家桶用户才能用

在中国市场，这个限制意味着**绝大多数用户被排除在外**。

**一句话总结**：Aeye-X R4s有最好的硬件配置（双摄+TOF+53°FOV），但被投屏限制锁死了用户群。它解决了"能离线OCR"，但没解决"能显示在哪里"。

#### 产品4：翠鸟慧眼Aeye-T 04（眼镜光学）

```
定位：最轻便的纯光学助视眼镜
价格：未公开（估计¥3,000-5,000）
核心卖点：解放双手 + 近远两用 + 50g
```

**参数亮点**：

- 近远两用（20cm到无穷远）
- 瞳距可调
- 无需电池
- 10年以上使用寿命

**这根本不是电子产品**，它是把望远镜缩小成眼镜形态。

和OCUTECH对比：

| 参数 | OCUTECH Sport II | Aeye-T 04 |
|------|-----------------|-----------|
| 重量 | **23g** | 50g |
| 近处对焦 | 22.86cm（需加近用镜） | **20cm到∞** |
| 放大 | 4x/5x/6x | 光学放大 |
| 目镜形状 | 长方形（视野更宽） | 圆形 |
| OCR/AI | ❌ | ❌ |
| 价格 | ¥5,000-8,000 | 未公开 |

Aeye-T 04的优势是近远两用不需要切换配件，劣势是重量更重、视野更小、价格未知。

**一句话总结**：Aeye-T 04是OCUTECH Sport II的"中国版替代"，但性价比和性能都不如原版OCUTECH。

#### 翠鸟整体战略分析

翠鸟在做一个"光学+电子+AI"的混合产品线，但三条线都没有做到极致：

```
光学线（Aeye-T 04）：不如OCUTECH轻便
电子线（Aeye-P4）：不如12寸斯诺功能全
AI/AR线（璧羽/R4s）：不如Seeing AI免费
```

**核心问题：AI能力是假的**

翠鸟一直宣传自己有"AI助视"能力，但实际上：

| 宣传的AI功能 | 实际实现 | 可用性 |
|-------------|---------|-------|
| OCR识别 | ✅有 | ⚠️璧羽要联网/P4要联网/R4s只能苹果 |
| 人脸识别 | ❌ | 无此功能 |

### 4.3 翠鸟失败案例的三个关键教训

#### 教训1：联网OCR等于没用

璧羽和Aeye-P4都踩了这个坑：
- 辅具的核心使用场景是学校、户外、考试——这些地方网络不稳定
- 联网OCR在关键时刻（考试、上课）会失效
- 残联采购评估时，离线能力是硬指标

**Dream Glass 4K如果要进残联目录，必须解决离线OCR。**

#### 教训2：平台锁定是自杀

Aeye-X R4s的"仅Mac/iOS投屏"设计，等于放弃了中国99%的用户：
- Windows市场份额>90%
- Android市场份额>70%
- 苹果用户<20%

**Dream Glass 4K是Android系统，这反而是优势——不要学R4s的平台锁定。**

#### 教训3：硬件配置不等于用户体验

R4s有最好的硬件（双摄+TOF+53°FOV），但因为平台限制，用户根本用不了。

**Dream Glass 4K的关键不是硬件参数，而是：**
1. 功能能不能用（OCR是否离线）
2. 用户能不能接受（价格、外观、重量）
3. 残联能不能采购（资质、价格）

## 五、我们能做什么

### 5.1 Dream Glass 4K的机会窗口

Dream Glass 4K是一个Android眼镜。它的核心优势不是"技术领先"，而是：

**硬件已经存在，边际成本为零。**

这句话的意思是：不需要重新做硬件，不需要开模，不需要供应链，直接用现有眼镜，装上软件就是产品。

这是一个极其罕见的产品机会——**硬件免费，软件就是产品**。

---

### 5.2 真实的产品方向分析

从"能做什么"角度，结合公益+残联采购的商业模式：

#### 方向A：免费方案验证（今天就能做）

安装Seeing AI + 基础APP到Dream Glass 4K：

```
成本：¥0
周期：今晚
产出：验证OCR朗读在眼镜上的体验
风险：低（即使失败也知道答案）
```

**这个方向的价值**：不是做产品，是做调研。在花任何时间开发之前，先知道眼镜上跑Seeing AI的真实效果——摄像头对焦是否合适、语音播报是否刺耳、操作是否反人类。这些只有实测才知道。

**判断**：这个方向值得立刻做，不是为了做出产品，是为了拿到真实的用户反馈。

---

#### 方向B：OCR朗读眼镜（核心差异化）

**做什么**：用Dream Glass 4K + 百度/腾讯OCR API，做一个"看到什么读什么"的眼镜。

**为什么这个方向有意义**：
- 辅具市场没有这个产品（所有辅具都没有中文离线OCR）
- 瑞杰珑12寸斯诺有离线OCR，但要¥4000+且桌面形态
- 真正填补"朗读"这个市场空白

**关键约束**：近处OCR对摄像头对焦有要求。OCUTECH的Falcon是"全球首款自动聚焦光学助视器"——这说明近远景切换是行业难题。Dream Glass 4K的内置摄像头对焦能力未知，需要测试。

**判断**：这个方向是核心，但方案选择取决于测试结果。先做方向A，用数据决定方向B的方案。

---

#### 方向C：障碍物检测（高价值，但有争议）

**做什么**：实时检测前方障碍物，语音播报距离。

**为什么争议**：
- 辅具市场完全没有这个功能（SideSight是偏盲专用）
- TensorFlow Lite有成熟的目标检测模型
- 但：白化病人的障碍物需求和偏盲不同——他们不是"看不到半边"，而是"全面模糊"。全模糊情况下，障碍物警报的有效性存疑

**需要先回答的问题**：
1. 0.01视力的人在室内走动的速度是多少？（太快的话警报来不及）
2. 障碍物警报对全模糊视力的人有多大帮助？
3. 夜间情况怎么处理？（暗处视力更差，但红外检测方案成本高）

**判断**：这个方向长期有意义，但需要先做用户调研（找月亮孩子之家的用户访谈），不能闭门开发。

---

#### 方向D：人脸识别播报（差异化功能）

**做什么**：识别熟人，播报姓名。

**市场现状**：辅具行业这个功能完全空白。

**技术可行性**：Seeing AI已经实现了这个功能，而且是免费的。

**价值分析**：这个功能对社交的帮助程度，取决于用户场景。重度依赖熟人社交的用户（大学生、住校生）价值高；轻度用户（工作党、成人）价值低。

**判断**：技术门槛低（直接用Seeing AI），用户价值中等。可以整合进方向B，不单独做。

---

### 5.3 资源约束下的优先级建议

假设只有一个开发者的资源（时间有限），结合公益+残联采购的商业模式：

| 阶段 | 时间 | 做什么 | 验证什么 | 产出 |
|------|------|--------|--------|------|
| 第0周 | 今晚 | 安装Seeing AI到眼镜 | 近处OCR效果、远距离对焦、语音播报质量、放大倍数够不够 | 真实的用户体验数据 |
| 第1-2周 | 用户调研 | 联系月亮孩子之家用户 | 障碍物警报的真实需求、近远景比例、目标用户画像 | 产品方向确认 |
| 第3-6周 | 开发 | 自定义Launcher | 三个按钮的交互体验 | 可演示的产品原型 |
| 第7-10周 | 开发 | 近处OCR优化 | 摄像头对焦调优 | 功能完整的版本 |

**不做**：不要一开始做障碍物检测，不要做独立APP。这些是方向C/D，长期才考虑。

**原因**：产品开发的第一原则是先验证核心假设（用户真的需要OCR眼镜吗？放大倍数够不够？）。在拿到真实用户反馈之前，任何高级功能都是假设。

## 六、残联采购：关键路径分析

### 6.1 残联采购的硬性要求

1. **在辅具采购目录内**：必须先进入省级/国家级辅具目录
2. **医疗器械资质**：可能需要NMPA认证（具体看类别）
3. **价格合理**：残联预算有限，价格不能太高
4. **功能实用**：经过验证，真实有效

### 6.2 进入残联目录的可能路径

| 路径 | 难度 | 时间 | 说明 |
|------|------|------|------|
| 现有目录分类 | 低 | 0 | 辅具目录已有助视器分类，可尝试申请 |
| 创新辅具申报 | 中 | 6-12个月 | 各省有创新辅具申报通道 |
| 医疗器械认证 | 高 | 12-24个月 | 需要临床验证，周期长 |
| 公益项目试点 | 低 | 3-6个月 | 先通过公益项目积累案例，再申请目录 |

### 6.3 建议策略

1. **先公益试点**：通过月亮孩子之家等公益组织，先免费发放试用
2. **积累真实案例**：收集用户反馈，证明产品有效
3. **申请创新辅具**：用真实案例申请省级创新辅具目录
4. **逐步进入采购**：进入目录后，通过残联系统销售

## 七、结论

### 三句话总结

**1. 辅具市场在做"放大"，用户在等"朗读"——这是一个根本性的需求错位。翠鸟的失败（联网OCR、平台锁定）证明了这一点。**

**2. Dream Glass 4K的独特价值不是技术领先，而是：硬件已存在，边际成本为零，软件就是产品。公益+残联采购的商业模式，决定了产品必须进辅具目录。**

**3. 最优先的事情不是开发，是实测。装Seeing AI到眼镜上，今晚就能验证放大倍数够不够、OCR朗读效果如何。**

### 关键发现汇总

**国外品牌的核心洞察**：
1. **eSight和IrisVision明确支持白化病** → 可以参考他们的临床数据和适应症描述
2. **OrCam的AI能力最强** → 但续航是致命弱点（1.5-2小时）
3. **IrisVision的Iris语音助手** → 最接近"私人助理"体验的辅具AI
4. **所有国外品牌价格都在¥20,000以上** → 国内残联采购几乎不可能

**国内外品牌的关键差距**：
1. **AI能力**：国外OrCam/IrisVision >> 国内所有品牌
2. **价格**：国外品牌是国内的5-10倍
3. **白化病支持**：仅eSight和IrisVision明确支持
4. **中文支持**：大多数国外品牌不支持或仅部分支持

**Dream Glass 4K的机会**：
- 用国内价格 + 接近OrCam的AI能力 = 残联采购的最优解
- 硬件已有，零边际成本
- Android系统，可安装Seeing AI等免费APP
- 需要解决的核心问题：离线能力 + 放大倍数验证
