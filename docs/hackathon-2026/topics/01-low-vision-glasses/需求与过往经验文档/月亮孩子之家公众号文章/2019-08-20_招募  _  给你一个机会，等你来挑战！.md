# 招募  |  给你一个机会，等你来挑战！

![](https://mmbiz.qpic.cn/mmbiz_gif/1UkOBnNLYFa1nSNsR2KDS0spia1tXEGTDibWmpyqf0YgoBTE3JTLKMfviaLGn4kRNOpgLiabNo0njic1RLDlkt19QtA/640?wx_fmt=gif)

随着一天天长大，我们总被生活要求着谨慎、沉稳。渐渐的却忘了自己勇敢、坚定、不畏困难的帅气模样，现在给你一个机会，让你来到拓展训练营和一群志同道合的朋友一起去挑战，去突破，让你重归热血，你愿意吗？

![](https://mmbiz.qpic.cn/mmbiz_png/AsmpJcWxWBUmpYtwicD0Tqy64DYvcmDRPmRqhCPjLBVUcmoz8IXGDgdVibjnSpQiaZoAJXRA6X1awqQR0KC3eHfhw/640?wx_fmt=png)

什么是拓展训练？

拓展训练是指，利用山川河流等自然环境，通过精心设计的的活动达到“磨练意志、陶冶情操、完善人格、提高凝聚力”的目的，拓展训练不但可以使个人在技能和心理上得到突破和锻炼，而且可以很快让参与者融入环境，体会与人配合的重要性。

**在这里你将有机会体验：**

![](https://mmbiz.qpic.cn/mmbiz_png/omOR0HEDIDzE6lM753s7beeFGbRiavNLIAUyenGFMibicjlic0n2H8QgvTd3licBDfU8P9CThvn3YBG1TQP0SHiaPmGQ/640?wx_fmt=png)

高空木板桥

高空木板桥极具个人挑战性，这要求挑战者必须具备勇气、信心、毅力和智慧，挑战者需要在九米高空，通过由几片木板串成的木桥，行走过程中木桥剧烈地晃动，挑战者要克服极大的心理障碍才能挑战成功。

水上晃桥

水上晃桥是一个团队比拼项目，两队人站在桥上，通过团队配合致桥摇晃，使对方队伍的成员落水，最后留在桥上的团队即为位获胜。这个项目不仅要求个人平衡能力，更要求团队共同出谋划策，相互交流经验，共同配合完成比拼。

![](https://mmbiz.qpic.cn/mmbiz_png/omOR0HEDIDzE6lM753s7beeFGbRiavNLIp84COgT2vq9J5bmfwz9WyMiblEqk4snc6tOtWTcZcf2TRvIO9DjJFBQ/640?wx_fmt=png)

![](https://mmbiz.qpic.cn/mmbiz_png/omOR0HEDIDzE6lM753s7beeFGbRiavNLIzVMlCB9Kj1E9iccezvt4TpF3wiaEK4cQ7EAvL8Xbzw6v7n785mkYeIQA/640?wx_fmt=png)

动力绳圈

动力绳圈除了是一个提高集体融入感的项目外，还是一个发泄情绪的好机会，所有队员围成一个圈，每个人紧紧握住手中的绳子向后倾，劲往一处使，顺时针方向转，由慢到快，幅度由小到大，大家一起高呼，喊出压抑、烦恼、委屈......

**我们都做了哪些准备？**

1、 我们挑选了自然风光与完善设施兼备的训练基地，在突破自我的同时极大满足身心放松的需求。 2、 我们邀请到了有着丰富拓展训练培训经验的专业教练，满足参与者体验感的同时保障我们的安全。 3、 在参与拓展训练营期间，为每位参与者购买保险，做到双重保障。

**我们为什么要做这件事情？**

社会对我们的要求好像早就被设定好，我们只能按照设定的轨道运行，我们的脾气性格被同化，潜力被埋没，我们变的小心翼翼，瞻前顾后，希望得到社会的认同和认可，这一次，我们希望有一个契机，能够让我们发现真正的自己，激发自我潜能，以更鲜明的自己再去融入集体。
