## Local acceptance

- A completed template is indexed, searchable and links to its source.
- Either language builds alone, with an original-language notice in the other interface.
- Invalid records report file paths and problems instead of disappearing.
- Metadata reflects actual source, status, authority and reviewer.
- Organization aggregation is separate from community candidates; project Issues and PRs keep their repositories.

## A real discussion later

A participant records confirmed points and open questions. Create a decision record only for a confirmed decision. Once someone accepts a community task, use one Issue and a documentation PR and link the result back. Candidate work is not an assignment.

No WeChat or Feishu content has been imported and no group message is sent.
