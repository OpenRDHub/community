## 协作身份与原始资料

公开协作使用 GitHub 账号或角色署名即可，不要求实名。确需实名对接的联系人信息放在限制访问的飞书资料中，不随公开快照同步。患者、家长及研究参与者的原始资料留在受限空间，公开版本另行整理；删除姓名并不能替代对经历、地点、时间、编号等可识别信息的检查。

普通技术示意图和产品操作截图，在来源及公开范围明确后可以原样归档。微信群二维码、个人资料截图和问卷原图不直接随文档批量公开。

## 后续资料如何进入仓库

资料提交人先注明来源、版本、可见范围和授权依据，再由一名资料负责人复核。涉及健康经历、微信群讨论或会议原文时，不以“群里发过”“外发版”或“能打开链接”代替公开确认。通过复核后再提交公开摘要或获准公开的附件。

待确认事项统一放在本仓库的 Issue / PR 中；公开讨论中只写资料类别和处理状态，不粘贴原始个人信息。资料负责人和复核人尚待社区确定。
