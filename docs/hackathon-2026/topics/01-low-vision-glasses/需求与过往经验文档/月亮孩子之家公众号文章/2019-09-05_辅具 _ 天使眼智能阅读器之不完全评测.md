# 辅具 | 天使眼智能阅读器之不完全评测

天使眼智能阅读器是由上海肇观电子科技有限公司研发的一款智能阅读设备。U盘大小，可通过一个吸附装置搭配任意眼镜使用。内置1300万像素高清摄像头和低功耗高性能处理器，集成了文字识别、手势跟踪、语音合成等多种人工智能技术。阅读器通过高分辨率的摄像头采集画面后，通过各种图像处理以及基于神经网络的文字识别技术，最终将文字转换为语音播报给用户。

**取出阅读器，我们首先可以看到它的操控面板，该面板由一个LED指示灯及一块触控面板组成，LED灯的不同颜色代表设备的不同状态，如绿色代表正常工作，蓝色闪烁代表待机状态，红色代表充电状态等，让使用者可以一目了然；触控面板支持单击、双击、长按、向前滑动、向后滑动五种操作，在不同情景下对应不同的功能。**

**在阅读器的一侧，可以看到一个物理按钮，该按钮为阅读器的开关，长按可对阅读器进行开关机操作，开机状态下短按可以进入待机或唤醒阅读器的操作；旁边有一个Type-C接口，可为阅读器进行充电，也可在阅读器工作时提供持续的电力供应，经实际测试发现该接口也有数据通讯的能力，后续应该可以通过该接口为阅读器升级固件或开发其他应用情景使用；阅读器后侧可以看到有悬挂环，使用者可通过其悬挂绳，便于阅读器的携带。**

**在阅读器的最前端可以明显的看到一个摄像头，这个摄像头就是阅读器能够阅读书籍的关键部件；阅读器背后可以看到有两片圆形磁吸装置及一个塑料挂架，通过该装置可以非常轻松的吸附挂接在安装了挂架的任何眼镜的镜腿上**

最后，通过以下几个方面对天使眼智能阅读器具体使用效果做个总结：

**识别率：**

![](https://mmbiz.qpic.cn/mmbiz_png/V0NCJaTA89uVAONrN7xQEjftPWpmVdzWpLGw31hSPYg9CMrFtoo8dicCc8KzZFrxUqzQ2pjDKpaYcfuicDPDAaSw/640?wx_fmt=png)

对于一般的书籍，特别是小说等大篇幅文字的横排文字书籍，作为一个不需依赖网络的离线袖珍设备而言，它的文字识别率是非常之高的，而且可以一次性拍摄并识别书籍的两面，是非常方便的；对于版式相对复杂的杂志等，如果文字分栏间距较小的时候则会出现跨区域阅读的情况；对于报纸，局部阅读尚且可以，但整版阅读由于字体较小且版式复杂，该阅读器尚无法完成阅读工作；同时经过实际测试，该阅读器目前并不支持竖版排版或者特殊字体的书籍。

![](https://mmbiz.qpic.cn/mmbiz_png/3CF7Ee4LqYcRXtuaAuwueDVITYa3zsNcyoQJib8KeWbkVFhwHxpqiapGDniaYjJd1tcFHWLma4ZBW2BQibktQCNpoA/640?wx_fmt=png)

![](https://mmbiz.qpic.cn/mmbiz_png/3CF7Ee4LqYcRXtuaAuwueDVITYa3zsNcyoQJib8KeWbkVFhwHxpqiapGDniaYjJd1tcFHWLma4ZBW2BQibktQCNpoA/640?wx_fmt=png)

**文字阅读：**

对于中文及英文，目前该阅读器均可以提供阅读支持，但目前仅限一种女声，并无其他人声可供选择；阅读速度方面，有多档可调，可适用习惯不同语速阅读的人使用；实际书籍阅读中，发现经常会出现在第一行末尾及第二行开头的两个字之间出现无故的停顿，反而在段落与段落之间没有明显的停顿等情况；同时有一些字形较为相近的文字如“干”和“千”字就容易读错；也会出现一些如大标题直接忽略不阅读的情况。

**操控：**

![](https://mmbiz.qpic.cn/mmbiz_png/V0NCJaTA89uVAONrN7xQEjftPWpmVdzWpLGw31hSPYg9CMrFtoo8dicCc8KzZFrxUqzQ2pjDKpaYcfuicDPDAaSw/640?wx_fmt=png)

天使眼智能阅读器的开机速度较慢，长按开关5秒钟后先亮起红灯，熄灭后数秒后才有开机音乐并伴随绿灯亮起，从按下开机按钮到绿灯亮起需要近半分钟；该阅读器整体的操控比较简洁，不过对于仅通过触控面板进行操作的方式相信大部分朋友应该需要适应一段时间才可熟练掌握；同时受体积大小的限制，天使眼智能阅读器并未设计耳机接口，目前仅能支持外放阅读，因此阅读文字时可能会影响到旁边工作或休息的人；不过阅读器自身音量大小可调，安装在眼镜镜腿上距离耳朵较近，安静的环境下设置较小的音量使用者自身也是可以清晰的听到声音，且厂家已确认后续通过升级固件可以连接蓝牙耳机进行使用，以确保使用者在使用阅读器时不会影响到他人，同时也可以在更为吵杂的情境下使用。

![](https://mmbiz.qpic.cn/mmbiz_png/3CF7Ee4LqYcRXtuaAuwueDVITYa3zsNcyoQJib8KeWbkVFhwHxpqiapGDniaYjJd1tcFHWLma4ZBW2BQibktQCNpoA/640?wx_fmt=png)

![](https://mmbiz.qpic.cn/mmbiz_png/3CF7Ee4LqYcRXtuaAuwueDVITYa3zsNcyoQJib8KeWbkVFhwHxpqiapGDniaYjJd1tcFHWLma4ZBW2BQibktQCNpoA/640?wx_fmt=png)

**续航：**

实际续航稍有欠佳，评测时不停的拍照及文字识别操作大概可以连续使用1个多小时，相信正常使用情况下续航时间应该会更长一些，但总体来看其续航时间仍相对较短，不过对于如此小巧的体积而言倒也可以理解；好的一点是经过实际测试，该阅读器是可以边充电边工作，因此使用者可以通过充电宝甚至手机的供电功能让该阅读器拥有持续的电力，只不过就需要连上充电线使用了。

**其他：**

![](https://mmbiz.qpic.cn/mmbiz_png/V0NCJaTA89uVAONrN7xQEjftPWpmVdzWpLGw31hSPYg9CMrFtoo8dicCc8KzZFrxUqzQ2pjDKpaYcfuicDPDAaSw/640?wx_fmt=png)

阅读器自身支持WIFI和蓝牙连接，也有相应的手机APP，但目前阅读器的WIFI和蓝牙似乎仅限阅读器与手机APP连接及升级固件使用，由于我们拿到的是该阅读器量产后的第一批版本，因此蓝牙连接耳机的功能还并未实现，不过相信随着厂家对于阅读器固件及手机APP的不断更新，蓝牙连接耳机，以及宣传品中手指跟随阅读等功能都可以轻松实现。

![](https://mmbiz.qpic.cn/mmbiz_png/3CF7Ee4LqYcRXtuaAuwueDVITYa3zsNcyoQJib8KeWbkVFhwHxpqiapGDniaYjJd1tcFHWLma4ZBW2BQibktQCNpoA/640?wx_fmt=png)

**展望：**

可以畅想下说不定不久的将来，在厂商的研发升级后，该阅读器甚至可以通过自身的网络通讯功能，实现一系列更高级的在线识别体验，包括更精准的文字识别阅读，甚至是更为复杂和丰富的图像辨识别功能，为视力障碍者提供更多的帮助。
