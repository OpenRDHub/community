# Community Library

Keep the discussion, the reasons for decisions, and the next steps available to people who join later.

The proposed library covers meeting notes, topic discussions, decisions, daily materials, and community proposals. Markdown in the community repository generates the website. Use WeChat groups for everyday discussion and Feishu for collaborative drafting. Original chats and documents retain their respective sharing boundaries.

- [Full proposal](plan.en.md): tool responsibilities, repository structure, workflow, and rollout.
- [Record policy](record-policy.en.md): intake, updates, access, and sources.
- [Meeting template](../../templates/meeting.en.md), [discussion template](../../templates/discussion.en.md), [daily template](../../templates/daily.en.md), [decision template](../../templates/decision.en.md).

This preview contains proposals and templates. It is not connected to WeChat or Feishu and contains no imported real meetings or WeChat discussions. Illustrative records are hidden by default and explicitly labeled.
