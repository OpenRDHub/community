# 社区资料中心

把事情怎么讨论、为什么这样决定、下一步由谁接住，留给后来参与的人。

这里拟收录会议纪要、主题讨论、决定记录、每日新增资料和社区方案。文档保存在 community 仓库，网页由同一批 Markdown 生成。微信群用于日常讨论，飞书用于协作整理；原始聊天与文档继续按各自的分享范围保存。

- [完整方案](plan.md)：工具分工、仓库安排、日常流程和试行计划。
- [收录与维护约定](record-policy.md)：哪些内容入库、如何更新、怎样处理权限和来源。
- [会议纪要模板](../../templates/meeting.md)、[讨论整理模板](../../templates/discussion.md)、[每日资料模板](../../templates/daily.md)、[决定记录模板](../../templates/decision.md)。

当前展示的是方案与模板，尚未接入微信或飞书，也没有导入真实会议或微信群聊。网页中的示例默认隐藏，并明确标记为示例。
