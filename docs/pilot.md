# 本轮修订与协作试行

以真实的“修复社区入口与记录收录”为技术任务，授权来自本次工作对话；不代表已召开会议或其他人已承诺接待。

[工作记录](../records/updates/2026/community-route-repair.md) → [Issue #1](https://github.com/OpenRDHub/community/issues/1) → PR（准备中） → 验证通过：模板收录、单语回退、元信息、链接、失败保留旧站点、独立仓库构建。

## 本地先验收

- 填写会议模板后，记录能被搜索、打开原文。
- 只交中文或英文均能构建，另一语言页面提示原文语言。
- 不合格 records 文件报出文件名和问题，不静默漏收。
- 页面显示实际来源、状态、主版本和复核人。
- 组织汇总与社区候选看板分开，项目 Issue/PR 保留原仓库。

## 下一次真实讨论怎样接进来

参与者整理主题讨论或会议记录，区分已确认和未决内容；确有决定才形成决定记录。确认一项有人接手的社区事务，用单一 Issue 和文档 PR 完成，再回链记录。没有本人确认时，不标成已认领。

本轮未导入微信或飞书内容，也不回贴微信群。
