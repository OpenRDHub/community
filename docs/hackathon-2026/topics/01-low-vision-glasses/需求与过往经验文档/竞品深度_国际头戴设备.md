# 竞品深度调研：国际头戴式/眼镜式低视力助视设备

> **调研时间**：2026-09-18
> **方法**：官网产品页/价格页 WebFetch 直接抓取 + WebSearch 补充第三方价格与评测（新闻类检索限定近 3 年）

## 0. 阅读须知：本行业的三个结构性事实

1. **这个行业的定价锚点在 3,000–5,000 美元区间**，全部五家厂商无一例外。头戴式助视设备是「医疗器械级小批量硬件」，规模效应弱，成本结构决定了它无法像消费级 AR 眼镜（Meta Ray-Ban $299 起）那样定价。
2. **分成两个技术门派**：①**视觉增强派**（eSight、NuEyes、IrisVision）——用摄像头+近眼屏把画面放大/增强，用户仍要"用眼去看"；②**AI 转述派**（Envision、OrCam）——不做显示，把视觉信息转成语音。**白化病患者（视力 0.1~0.3，有残余视力且畏光）同时落在两派之间的空档**：既要放大，又要朗读。
3. **中国区几乎全部空白**。五家在官方渠道层面均未开出面向中国大陆的正式销售/售后体系（详见各章节与横向表）。这既是风险（无竞品参照、无供应链），也是机会（残联采购场景下的先发位置）。

### 7.1 矩阵读出的关键结论

**没有任何一家同时满足"高倍放大 + OCR 朗读"两项。** 这是本次调研最核心的结论：

- **放大最强者（eSight 24x）** → 朗读能力最弱（官网未列 OCR），且完全不遮光。
- **朗读最强者（Envision / OrCam）** → 完全没有放大能力，且完全不遮光。
- **唯一官方同时点名"眼白化病 + 眼球震颤"的（NuEyes）** → 放大只到 12x，且无防抖说明、有线连手机。
- **唯一在软件层面处理畏光的（IrisVision 反色/降眩光模式）** → 是"软件模拟"，不是物理遮光，且未针对眼震说明。

**白化病患者的"放大 + 朗读 + 遮光 + 眼震容忍"四重需求，在现有国际产品中是一个明确的产品空档。**

## 8. 对白化病 AR 眼镜产品的启示

### 启示 1：不要把"放大"和"朗读"当二选一——双通道并存才是白化病刚需
五家产品全部站在路线的一侧：视觉增强派不做语音转述，AI 转述派不做放大显示。但白化病患者的实际状态是**有 0.1~0.3 残余视力、且畏光**——他们会**交替使用**"放大看清"（读课本标题、认脸）和"朗读听懂"（读长文、读标签）。第三方适配指南也明确把白化病归入"对放大、滤光片和稳定图像电子助视器响应良好，同时**智能眼镜的免手 OCR 可减少长时间阅读的视疲劳**"这一类（https://floridareading.com/blogs/news/unlocking-independence-assistive-technology-solutions-for-specific-eye-conditions ）。**产品定义上应把放大显示与 OCR 朗读做成同一台设备的两条并行输出通道，而不是版本切割。**

### 启示 2："眼震容忍"是白化病场景的差异化技术壁垒，但五家几乎无人认真做
NuEyes 是唯一在官网适应症里明确列出 `Nystagmus` 的厂商，却**没有给出任何技术解释**；eSight 有图像防抖与画面冻结但从不提眼震；OrCam 是最"抗眼震"的交互（手势指读、不需对齐光轴）却完全不做防抖宣传。这说明：**眼震友好度是一个既被承认、又未被工程化解决的空白**。可针对性地做三件事——① 画面冻结 + 稳定后自动 OCR（把"抖动"从问题变成触发条件）；② 不依赖头位/眼位精对准的"拍摄即读"；③ 交互上彻底放弃需要凝视对齐的 UI（如凝视选中）。这三项组合起来，是这个赛道目前无人占位的技术叙事。

### 启示 3：畏光必须有物理方案，软件反色不够
五家中只有 IrisVision 在软件层面处理畏光（Inverted Text 反色 + Television 模式降背光眩光），且其官网明说反色模式"reduces the glare"、面向高光敏感人群（https://irisvision.com/low-vision-aids-enhancing-your-view/ ）。但白化病的畏光是**光学层面的**——虹膜色素缺失导致无法有效控制进光量，临床共识是**滤光镜片（深红/琥珀/灰）+ 环绕式镜框 + 宽檐帽**这类物理手段（https://specialty.vision/article/achromatopsia/ ）。同时要注意一个矛盾：**滤光片在户外缓解畏光，但在室内会降低视力**（eSight 官网 OA 页自己就指出了这一点：https://www.esighteyewear.com/vision-loss/ocular-albinism/ ）。产品应做**可切换/可调光密度的遮光模块**（电动变色或磁吸遮光罩），而不是固定墨镜或纯软件滤镜。

### 启示 4：价格敏感 ≠ 只能做低价，关键是"可被机构支付"的结构
五家没有一家便宜，但**支付结构才是真正的分野**：eSight 靠 **VA 100% 全额覆盖**（https://www.esighteyewear.com/esight-go/ ），IrisVision 靠 VA + NIH/Johns Hopkins 的临床背书（https://irisvision.com/vista/ ），NuEyes 靠保险可能 100% 报销（https://www.nueyes.com/ ）。**最值得借鉴的是 Envision 的做法**：它明说"分版本（Read / Home / Professional）是为了让用户更容易对接 subsidies、grants 和 reimbursement"（https://cdrinfo.com/d7/content/envision-enhances-its-range-smart-glasses-blind-and-low-vision-communities-making-them-more ），并且用"个人自用版"和"机构/商业采购版"做清晰切分——**这正是残联采购场景需要的结构**。同时，Envision 的**终身功能更新（Professional 版）**和**$199/年订阅（Read/Home 版）**是五家中唯一的订阅制，对公益采购意味着长期成本确定性差，需谨慎设计。**建议：把设备款与软件服务费拆开，并预先设计"残联/公益基金采购包"，把可报销性作为产品参数来设计，而不是事后谈判。**

### 启示 5：B 端采购还有一个隐性门槛——售后与公司存续风险
OrCam 的案例是最直接的教训：**产品本身仍是顶级（13MP、22.5g、离线 OCR、140+ 语言），但公司被第三方报道称已关闭低视力研发、员工降至 50 人以下、在售为经销商库存**（https://www.onedayadvisor.com/2026/08/best-smart-glasses-for-visually.html ）。对残联这类需要"5–10 年维保、备件、软件更新"的采购方来说，**供应商存续能力是与产品参数同等重要的评分项**。反过来，这也是国产/本土化方案的结构性优势：交付周期短、备件可控、可对接本地残联与公益基金的验收与结算流程。**建议在立项时就准备"全生命周期成本 + 售后 SLA + 企业存续性"三张表，作为对国际竞品的降维打击点。**
