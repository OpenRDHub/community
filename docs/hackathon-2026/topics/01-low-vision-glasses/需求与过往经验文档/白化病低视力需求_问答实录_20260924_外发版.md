## **一、摘要**

关禄在 09-24 下午约一小时里，把白化病视力的底层机制讲清楚了：**白化"看不清"的根源不是对焦问题，而是眼底中心凹发育不良**——普通人眼底约 5000 万像素，白化患者仅约 500–2000 万像素，所以是"细节少"而不是"模糊"；因此**常规近视/远视/散光配镜基本无效**，唯一有效路径是把图像**放大到能辨识的程度**。

由此派生出的产品约束：助视时必须**遮光**（非透明镜片或磁吸挡光片）、放大之后要**防抖、低延迟、轻便、视场够大、操作简便**。

关于**眼球震颤**，关禄明确它不是主要问题，也不会导致放大后看不清文字——人眼分辨一个文字只需约 **1/10 秒**的注视时间，只要保证这个窗口即可。

## **三、关禄问答实录**

### **3.1 眼球震颤到底是什么感觉？**

**问（16:02）**：「眼球震颤的感觉是否是眼前景物无规律的晃动，眼睛无法正常聚焦呀？」

**关禄（16:12）**：「大部分情况下患者是感受不到的，人脑很强大的，会对这个震颤进行补偿，如果震颤幅度太大，脑子还会控制整个脑袋进行反方向的摆动来抵消震颤带来的视觉抖动，因此可以观察到有的水平眼震较为严重的患者看东西是脑袋会左右晃动。」

**追问（16:14）**：「震颤发生时是一个持续的过程」「不是短暂的一次，大约会持续多久呢？」

**关禄（16:15）**：「一直持续，有的患者在注视时可以控制震颤相对轻微一些。」

**关禄（16:16）**：「眼震的根源是大脑给控制眼球运动的肌肉和神经发送异常信号导致的，所以有些患者会有喝酒微醺后会有震颤减轻的感觉。」

**关禄（16:18）**：「不同人的眼震幅度，频率等都不同，而且一般眼球运动到某个角度眼震也会轻微甚至没有，如果这个角度没有在正中间，就会表现出有些患者喜欢侧着脑袋看东西，因为那个角度震颤轻微看东西省劲儿。」

**旁证（肖磊Lane 16:14，低视力患者）**：「我的个人经验是看到的东西并不会晃动，而是没办法长时间聚焦，看一处东西太久非常容易疲劳。」

**问（16:22）**：「如果别人从外观上近距离观察患者，会看到眼球左右转动吗？」

**关禄（16:23）**：「会。」**小结**：患者主观上多不觉得画面在晃（人脑会自动补偿），真实体验是**难以长时间聚焦、易疲劳**；眼震是持续性的，且个体差异很大。

### **3.2 真正的瓶颈：眼底中心凹发育不良**

**关禄（16:30）**：「对于白化而言，眼震对视力的影响并不是主要问题。主要问题是白化患者的眼底中心凹严重发育不良，导致的结果举个例子来说，普通人眼睛眼底是5000万像素，那白化的眼底可能只有500-2000万像素。」

**关禄（16:34）**：「所以相当于我们分辨能力比较低，对于需要精细视力分辨的地方就不行了。不过日常生活中，并不是时时刻刻都需要精细的分辨，所以我们走路、甚至骑车都没问题，因为可以看到人看到树看到车不会撞上去，但你要让我们看人脸、车牌、树叶这类，可能就得距离很近，物体在我们眼中有足够大的成像，我们能分辨了，才行。」

**关禄（配 OCT 眼底照片，16:42 / 16:46 / 16:48 / 16:49）**：

- 「中心凹，目前通过眼科OCT检查就可以很容易查出来。」
- 「比如这个，就是一个正常人眼睛的OCT照片……眼底中心凹的结构会很明显，很标准。」
- 「咱们人能看到东西，就是靠这块，这个区域就相当于相机的CMOS或CCD。」
- 「这个是某白化患者的OCT照片，可以看到原本中心凹的区域完全没有中心凹的结构，相当于几乎没发育。」

**关禄（16:51）**：「你想想，你不能说500万像素的相机照片，比5000万的'模糊'对吧，只能说5000万的可以包含更多细节。」**小结**："不是模糊，是细节少"——这是理解全部需求的起点。

### **3.3 常规验光配镜有没有用？**

**问（16:49）**：「普通的视力矫正眼镜对患者有效果吗？」

**关禄（16:50）**：「所以很多人也有个疑问，就说你们白化看东西是不是模糊的？但其实我们看东西是不模糊的，除非伴随高度近视、远视或散光，不过近视远视散光是可以通过常规配镜来矫正的。」

**关禄（16:52）**：「除非这个人有近视、远视和散光问题，戴那个才有用。」

**关禄（16:54）**：「常规的近视、远视和散光镜，对于我们不会有太大作用，除非这个人同时伴随有这部分问题。比如这个人恰好有600度近视，他裸眼视力可能是0.05，佩戴适合的眼镜后能矫正到0.1，这个也就是他最好的状态（也可以说是中心凹能给他提供分辨图像的最大能力了）。」

**关禄（16:56）**：「但对于不少的白化患者，比如本身裸眼0.1，但只伴随有200度近视的话，那么就算带上眼镜，可能视力连0.12都到不了，因此很多人也就不戴眼镜了。」

**关禄（16:52）**：「也不能完全这么说，比如看近处用放大镜，可以放大图像；看远处用望远镜，也可以放大图像。」**小结**：**常规配镜基本无效**；真正有效的是"放大"（放大镜 / 望远镜原理）。

### **3.4 助视器为什么必须遮光？**

**关禄（17:11）**：「目前市面上基于AR的助视器，一般也都会把前边搞成非透明，或者可以拆卸磁吸的当光片。当设备处于助视时是不能透过透明镜片看外界的，这个也是基于对低视力者的考虑，因为如果是透明的，那样画面会更杂乱，我们会更难以分辨，加上白化还都普遍畏光，因此如果是透明的话光线强的地方可能就很难看到屏幕上的内容了。」

**关禄（17:15）**：「是哎，所以如果AR方案的话，可以考虑外挂磁吸挡光片，或是用电子变色镜（液晶）那种原理来挡光？」

**旁证（崔华坤 17:13）**：「AR眼镜存在的问题是白天室外，如果不挡光的话，根本看不清显示的图像，哪怕是视力正常的人。」

**关禄（16:27，评某光学助视器）**：「比如这个助视器，因为光学目镜很小，虽然大部分白化患者是可以用，但少部分可能是由于眼震严重会导致看镜筒里的画面是抖动的而无法使用。」**小结**：遮光是助视模式的**必要条件**，不是可选项；同时"小镜筒式光学目镜"对眼震严重者不适用。

### **3.5 放大之后还需要什么？**

**关禄（17:03）**：「还要考虑操作简便，设备整体轻便，放大后的防抖，以及图像本身的延迟等。」

**关禄（17:04）**：「还有就是最好图像视野能大一些，目前AR的视场角说实在都不是很理想，VR的视野会更舒服，但VR的体积会更大。」

**关禄（16:38）**：「是的，也就是说在我们需要的时候，可以很方便的能把所需的图像放大到我们能够辨识的程度就行，如果在能对一些关键信息进行提取通过高对比度描边，或是单纯文字放大显示，或是有限的语音提示则更好。」

**关禄（16:59）**：「就算有近视远视这块，现在很多AR或VR眼镜也都可以通过内部镜片或外挂磁吸镜片来矫正这部分问题。」**小结**：进入工程约束阶段——**放大 + 防抖 + 低延迟 + 轻便 + 大视场 + 操作简便**；高对比描边 / 文字放大 / 语音提示为加分项。

### **3.6 眼震会不会把放大的字抖糊？**

**问（17:10）**：「对于眼震患者，即使将图像放大到能看清的程度，是否会因为眼球一直在抖动，也会导致看不清文字？」

**关禄（17:12）**：「不会的，上边也说了，人脑纠错能力很强大的。如果眼震真的幅度和频率太严重，也可以通过手术进行改善（但没法根除）。」

**关禄（17:13）**：「举个例子，比如你看到肖老师拍的视频眼球在摆动，但人眼可能看和分辨一个文字只需要1/10秒，虽然眼球摆动，但如果能提供1/10秒的注视时间，就足够了。」

**关禄（17:14）**：「所以现在有些做眼震手术的专家，也会着重判断中央注视时间这个数据，来作为是否建议手术的指证。」**小结**：眼震**不构成"放大后看不清"的否决项**——只要保证约 **1/10 秒**的有效注视窗口即可。**中央注视时间**可作为一条验收口径。

### **3.7 AR / VR 的视野问题**

**关禄（17:05）**：「AR的FOV不太行。」

**关禄（17:06）**：「苹果的VisionPro不就透视了嘛。」

**关禄（17:08）**：「苹果那个也是全包，无非是用多个摄像头采集了户外的画面，通过运算处理后又呈现到内部的屏幕上，而且延迟足够低，让人感觉上和没带是一样的。」**小结**：AR 的优势是走路可透视、劣势是 FOV 小；VR 视场更舒服，但需要靠"透视摄像头 + 低延迟"来补偿。此处正好与"必须遮光"相互牵制。
