# 回顾 } 在阳光下快乐前行   月亮孩子之家山东分站活动

一曲春魂，心怀美丽，悠长的守望涌动着神韵的三月天，行云流水间梦断天涯，幽香的诗句在无我的境界里寻找远古的风雨，释放情怀，悠悠心曲流淌着水一般的文字.......

清明假期，我们月亮孩子之家山东站组织了一次小型的聚会活动——走进春天，拥抱阳光。探访千年古城，游览云门圣境。

第一天我们在昌乐集合，这里有全国最大的珠宝城，看到琳琅满目的金银珠宝玉器，爱美的人儿怎么能不心动呢！

![](https://mmbiz.qpic.cn/mmbiz_png/omOR0HEDIDzlsPACOqvwtyvuSa9rhPOnWyjXfRSckMHMDiaIV9L6x7FSIibXicUcWqaia4T3k7M0Mv7Zd08NQ34LfQ/640?wx_fmt=png)

逛完了珠宝城，一定要吃一顿潍坊特色的朝天锅，这美味只有潍坊地区才会有哦！酒足饭饱，我们坐着热心的晓璐爸爸的中巴车赶赴青州古城，这可是我们心心念念的目的地呀！青州古城是古九州之一，有七千余年的发展史，五千余年的文明史，十二年的国都辉煌，先后存在过广县城、广固城、南阳城、东阳城、东关圩子城、旗城等六座古城池。

看，我们这位大月亮的母亲在古老的纺车旁操作起来如此轻盈。

瞧，多才多艺的晓璐玩起手鼓来还真是有模有样。

结束一天的行程，到了享用美食的时间。无论大家来自哪里，走到一起就是一家人。我们推杯换盏，分享着各自的生活和感受。济南莹姐的父亲谈起了自己儿女的成长经历，她的观点是，不要过于保护孩子，放开手让孩子自己去做，自己去闯，才是对孩子一生最好的养育。晓璐的父亲深有体会，提起自己的儿子，也是掩饰不住的欣慰与自豪。

![](https://mmbiz.qpic.cn/mmbiz_jpg/omOR0HEDIDzlsPACOqvwtyvuSa9rhPOnriaicz7jwkIEU5rAxGrIgibNUkf6Niao6PS4cRYTZj0ceMcBjQnJtshJaQ/640?wx_fmt=jpeg)

第二天我们的行程是游览云门山，自古为山东中部名山，也是青州的标志性景点之一。云门山主峰大云顶海拔421米，其山势巍峨峻峭、松柏叠翠，登上山顶可俯瞰青州城区，更是赏日出的好地方。

![](https://mmbiz.qpic.cn/mmbiz_jpg/omOR0HEDIDzlsPACOqvwtyvuSa9rhPOnXSDaIs8abTYick950vjYvSa0UwVmD8JmpD8kTVYH2Sf3NZ9YO6SUhNA/640?wx_fmt=jpeg)

很快我们便登上了俯瞰青州城的位置，来到云门洞，想象着云雾缭绕从此穿过的情景，来到“寿”字石刻下，体验一下“人无寸高”的说法。

我们山东站对将来的活动做了新的计划：即形成常态化聚会交流的活动机制，在省内不定期多组织丰富多彩的活动，每一次以一个地市作为活动中心，在当地征集热心的患者或家长作为志愿者，为大家提供服务，照顾到每个地区的伙伴，同时给大家提供更多可以交流学习的机会。

欢迎全国各地的小伙伴来美丽的山东，感受我们的热情。
