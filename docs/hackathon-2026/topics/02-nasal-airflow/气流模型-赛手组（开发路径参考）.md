# 1. 导入CT，使用开源工具，进行鼻腔气体建模

### tips

- 结果输出为 (.stl) 格式数据
- 可尝试 mitk 工具
- 鼻腔气体阈值大约为-∞ 到-400
- 注意：输出的stl模型需要排除头部外侧气体，鼻孔处体积和头部外侧空气需要正常切分（右侧画笔的红色区域）

![图片为一个侧脸轮廓图，黑色线条勾勒出头部轮廓，红色线条突出显示鼻腔区域。该图与文档中“鼻腔气体阈值大约为-∞到-400”及“输出的stl模型需要排除头部外侧气体，鼻孔处体积和头部外侧空气需要正常切分（右侧画笔的红色区域）”的内容相关，直观呈现了鼻腔在头部轮廓中的位置，帮助理解在进行鼻腔气体建模时，需将鼻孔处体积和头部外侧空气正常切分，排除头部外侧气体这一操作要求。](https://feishu.cn/file/CuFQbYUuvoTabRxzyjjcNKWrnGh)
