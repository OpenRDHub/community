*版本：v1.0（2026-08-24）*

## 核心概念

### 普通放大 vs 注视点放大

**普通放大（传统模式）：**
```
┌─────────────────┐
│                 │
│    整个画面      │
│    都放大了      │
│   （全部放大）    │
│                 │
└─────────────────┘
问题：只能看到一小块，像"通过吸管看世界"
```

**注视点放大（目标功能）：**
```
┌─────────────────┐
│  整页书的内容     │
│  都可以看到      │
│                 │
│    ┌──────┐    │
│    │这一个│ ← 视线停在这里
│    │字放大了│    │
│    └──────┘    │
│                 │
│  周围还是正常的   │
└─────────────────┘
效果：周围视野正常，只有视线焦点处放大
```

## 注视点放大原理

### 工作流程

```
用户眼睛看向"中"字
    ↓
红外眼球追踪器捕捉眼球位置
    ↓
计算视线落在图像的哪个点
    ↓
只放大那个点周围的区域（比如一个字的大小）
    ↓
渲染：正常视野 + 局部放大
    ↓
用户看到：整页可见，但视线焦点处放大了
```

### 渲染逻辑

```python
class GazeContingentZoom:
    def __init__(self):
        self.zoom_radius = 1.5  # 放大区域半径（字体大小单位）
        self.zoom_factor = 3.0  # 放大倍数
    
    def render(self, frame, gaze_point):
        """
        frame: 原始画面
        gaze_point: 视线位置 (x, y) 归一化 0-1
        """
        # 1. 创建正常视野（全画面轻微放大，保持清晰）
        output = self.light_zoom(frame, 1.2)  # 1.2倍轻微放大
        
        # 2. 在视线焦点处创建局部高倍放大
        x, y = int(gaze_point.x * frame.width), int(gaze_point.y * frame.height)
        
        # 提取注视点周围区域
        radius = self.zoom_radius * 字的高度
        zoom_region = frame[y-radius:y+radius, x-radius:x+radius]
        
        # 高倍放大这个区域
        zoomed = cv2.resize(zoom_region, 
                          (radius*2*self.zoom_factor, 
                           radius*2*self.zoom_factor))
        
        # 3. 混合：周围正常 + 焦点放大
        output = self.blend(output, zoomed, gaze_point, radius)
        
        return output
```

## 眼球追踪模块

### 技术规格

| 参数 | 数值 |
|------|------|
| 采样率 | 60-120Hz |
| 精度 | 0.5-1度视角 |
| 延迟 | <20ms |
| 成本 | ¥80-150 |

### 工作原理

```
眼镜内部结构：
┌───────────────┐
│ 红外摄像头    │ ← 朝向眼睛
│ （捕捉眼球）  │
└───────────────┘
        ↓ 红外光照射眼球
        ○ ← 眼球
       /|\
      / | \ ← 虹膜/瞳孔
摄像头捕捉 → 计算瞳孔位置 → 映射到图像坐标
```

## 眼球震颤补偿

### 问题

```
正常眼球运动：← → ← → ← → ← → （平滑移动）
眼球震颤：←←→→→←←→→→← （抖动、不自主运动）
```

### 解决方案

```python
class NystagmusCompensator:
    def __init__(self):
        self.gaze_history = []  # 保存历史注视点
    
    def get_stable_gaze(self, current_gaze):
        # 眼球震颤特征：高频、小幅度、周期性
        # 用低通滤波平滑
        smoothed = self.low_pass_filter(self.gaze_history)
        return smoothed
    
    def low_pass_filter(self, history):
        # 去掉高频抖动（震颤）
        # 保留低频运动（真正的视线移动）
        return np.mean(history[-5:])  # 简单平均
```

### 效果

| 状态 | 效果 |
|------|------|
| 震颤补偿前 | 注视点跳动严重 |
| 震颤补偿后 | 注视点平滑稳定 |

## 文字增强

### 什么是文字增强？

```
原始文字：灰度不够，边缘模糊
增强后：黑色字体，白色背景，边缘锐利
```

### 算法实现

```python
class TextEnhancer:
    def enhance(self, image, text_region):
        # 1. 灰度化
        gray = cv2.cvtColor(image, cv2.COLOR_BGR2GRAY)
        
        # 2. 自适应对比度增强（CLAHE）
        clahe = cv2.createCLAHE(clipLimit=3.0, tileGridSize=(8,8))
        enhanced = clahe.apply(gray)
        
        # 3. 边缘锐化
        kernel = np.array([[-1,-1,-1],
                          [-1, 9,-1],
                          [-1,-1,-1]])
        sharpened = cv2.filter2D(enhanced, -1, kernel)
        
        # 4. 二值化（让字更黑、背景更白）
        _, binary = cv2.threshold(sharpened, 0, 255, 
                                  cv2.THRESH_BINARY + cv2.THRESH_OTSU)
        
        return binary
```

### 增强效果

| 效果 | 原始 | 增强后 |
|------|------|--------|
| 对比度 | 3:1 | 21:1 |
| 边缘 | 模糊 | 锐利 |
| 背景 | 干扰 | 干净 |

**对于白化病人的价值：**
- 视网膜感光细胞少
- 对比度敏感度低
- 增强后更容易辨认文字

## 三者协同

```
用户看一个字
    ↓
眼球追踪：捕捉视线位置
    ↓
震颤补偿：稳定注视点
    ↓
注视点放大：只放大那个字
    ↓
文字增强：增强对比度和锐度
    ↓
用户看到：放大的、清晰的字，周围还是正常视野
```
