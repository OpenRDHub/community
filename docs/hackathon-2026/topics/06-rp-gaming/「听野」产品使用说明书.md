# 「听野」产品使用说明书

**听野（SenseField）安装与使用说明**
本文以2026年10月1日的安装包及vivo手机界面为例；不同版本、机型的页面名称可能略有差异。

目前仅限安卓，并无适配苹果。

**第一步：下载安装包**

两种方式选其一。

<p>a.直接下载</p><p>飞书附件未随本仓库归档，请查看原文或项目的正式发布页。</p><p>版本：v0.3.5</p><p>更新日期：2026年10月2日 22:55</p><p>说明：关注更新时间，不定期更新。</p><p></p><p>b.浏览器下载</p><p>使用手机浏览器打开项目的 GitHub Releases 页面：</p><p>https://github.com/ld0574/SenseField/releases</p><p>若页面无法正常打开，请检查网络连接.</p><p>在发布页面找到需要安装的版本，展开 Assets（资源文件）。</p><p>原文截图尚未归档，请向资料负责人索取可公开版本。</p><p>点击扩展名为 .apk 的安装包，下载完成后按手机提示</p><p>安装“听野”。仅安装来自可信项目页面的文件。</p>

**第二步：进入权限设置**
打开“听野”，在“选择辅助游戏”页面点击“王者荣耀”的“开始辅助”；进入“王者荣耀辅助”页面后，依次点击“设置”和“授权与运行设置”。



[原图（飞书，需访问权限，尚未归档）](https://feishu.cn/file/UpgVbdYdJoXKEIxBEf0c44VenPe)


[原图（飞书，需访问权限，尚未归档）](https://feishu.cn/file/UWwFb2cCZoRk6gxImlzcYNOzn3a)


[原图（飞书，需访问权限，尚未归档）](https://feishu.cn/file/Xve1blVaWotNtbxf2F1csKOJnxc)



**第三步：设置运行权限**
在“授权与运行设置”页面依次检查运行通知、置顶视觉提示和后台省电策略。以下以 vivo 手机为例，其他机型请查找相近的系统设置项。

[原图（飞书，需访问权限，尚未归档）](https://feishu.cn/file/MsvXbTZDfo46Tbxlb7Sc8KounPb)

运行通知：点击“授权运行通知”，在跳转的系统页面为“听野”开启“允许通知”。

[原图（飞书，需访问权限，尚未归档）](https://feishu.cn/file/BpBBbkpqZo0ythxj1WMcsVIgnvd)

置顶视觉提示：如需使用此功能，勾选“允许使用视觉提示”，点击“授权置顶显示”，再在系统悬浮窗应用列表中找到“听野”并开启权限。请避免提示遮挡游戏画面。

[原图（飞书，需访问权限，尚未归档）](https://feishu.cn/file/XRzXbjRpwoR0fcxA4bHcsy1BnYd)

后台省电策略：点击“系统省电优化设置”，在系统应用列表中选择“听野”，设置为“允许后台高耗电”，以减少后台运行时被系统停止的情况。



[原图（飞书，需访问权限，尚未归档）](https://feishu.cn/file/UXSvbwQGroS7iwxyLDbcFhHanUe)


[原图（飞书，需访问权限，尚未归档）](https://feishu.cn/file/PcXPb4vsro61xYxl4VicCBiCn5R)


[原图（飞书，需访问权限，尚未归档）](https://feishu.cn/file/WW4abRZfno8qqJxNaA4ccSi4nhg)



**第四步：测试与调整提醒**
返回“王者荣耀辅助”页面，打开“配置与调参”。点击“测试提醒”和“测试震动”，确认语音与振动正常；如需调整播报效果，可选择语音引擎并调节语速。

[原图（飞书，需访问权限，尚未归档）](https://feishu.cn/file/F2iXbx6sRoEDVvxBVz5cOCxWnHh)

**第五步：启动或停止辅助**
确认设置无误后，返回“王者荣耀辅助”页面点击“开始”，让app录制屏幕后即可打开王者荣耀；
结束使用时点击“停止”。若没有收到提醒，请检查通知权限、系统音量及省电设置。



[原图（飞书，需访问权限，尚未归档）](https://feishu.cn/file/JYrcbGCoCo1jQsxIRxfcoSD1njN)


[原图（飞书，需访问权限，尚未归档）](https://feishu.cn/file/YuYPbYsLhoCXKHxpSwBcwKZLndR)



当“王者荣耀辅助”页面中的运行状态显示为“正在运行”之后即可打开王者荣耀正常游玩了。
