# 2019年助视器发放名单公示

![](https://mmbiz.qpic.cn/mmbiz_png/eyHaP6oxDbg0q3qxqFqddS3FxbfWCwQMkiagrQ8icur8X9KpI4c3UO7HUCMcPFIIJphmEG8kDM2XqTdzfq5eaLAw/640?wx_fmt=png)

月亮孩子之家经过对申请者的信息进行筛选，结合两年内多个渠道辅助器具发放的情况，在尽可能平衡公平原则及申请者需求原则的基础上，审核并通过了2019年度141名视力辅助器具发放对象，这些受助白化病患者将根据其申报表中的视力、需要解决的问题等情况，得到适合的视力辅助器具壹套，包括但不限于偏光镜、光学手持式放大镜或望远镜、光学头戴式放大或望远镜等，以改善其视觉功能，提高其生活、学习品质。

![](https://mmbiz.qpic.cn/mmbiz_png/eyHaP6oxDbg0q3qxqFqddS3FxbfWCwQMkiagrQ8icur8X9KpI4c3UO7HUCMcPFIIJphmEG8kDM2XqTdzfq5eaLAw/640?wx_fmt=png)

由于部分供应商备货周期较长，该批次助视器具体发放时间预计在9月前半月，我们在向受助者发出快递时会同时发送手机短信息进行提醒，届时请注意查收。如果对公示表中的受助者有任何异议，或是申请人本人的收件地址有变更的情形，请尽快和我们联系。联系电话：400 998 2155
