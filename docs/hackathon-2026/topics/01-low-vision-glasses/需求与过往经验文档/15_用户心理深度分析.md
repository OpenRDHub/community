# 用户心理深度分析：白化病低视力人群到底需要什么

> 日期：2026-09-01
> 来源：真实故事 + 用户访谈提纲 + 翠鸟失败案例

---

## 一、核心发现：用户最怕的不是"看不清"，而是"麻烦别人"

### 真实案例

**高瑞敏（视力0.01，考上211研究生）**

> "看不清老师在黑板上写的是什么"
> "同桌一句一句念给她听"

**徐苛苹（视力0.03）**

> 一节课举**几十次望远镜**，手酸、肩颈酸痛
> 但她宁愿自己累着，也不愿"麻烦别人"

**张艺瑄（视力0.01，上清华）**

> 记忆力极强——"看过的都能记住"
> **看不清，但能记住**——这是她的生存策略

---

## 二、用户心理5大痛点（按优先级）

### 🥇 痛点1：不想麻烦别人（最深层心理）

**用户原话**：
- "我不想让同桌一直念给我听"
- "我不想成为别人的负担"
- "我能自己解决的就自己解决"

**背后的心理**：
- 自尊心——不想被贴上"需要帮助"的标签
- 内疚感——觉得麻烦别人是自己的问题
- 独立意识——渴望像正常人一样生活

**产品启示**：
- 不要强调"帮助"，要强调"独立"
- 不要说"给盲人用的"，要说"让你自己搞定一切"
- 核心价值主张：**"不求人"**

---

### 🥈 痛点2：不想被看出来（自尊心）

**用户原话**：
- "我不想被同学当成异类"
- "我不想让老师特别照顾我"
- "我不想被投以异样眼光"

**背后的心理**：
- 白化病外貌已经引人注目，不想再加一层
- 青少年时期尤其敏感
- 渴望"正常"，不想被"特殊化"

**产品启示**：
- 产品要**看起来普通**
- AR眼镜要像普通眼镜
- 不要设计成"科技感十足"的样子
- 核心价值主张：**"看起来很正常"**

---

### 🥉 痛点3：怕花钱买错（损失厌恶）

**用户原话**：
- "这么贵，万一不好用怎么办？"
- "我先试试再决定"
- "我不敢冒险"

**翠鸟失败案例**：
> 翠鸟失败的根本原因：家长不敢买

| 翠鸟的问题 | 用户心理 |
|-----------|---------|
| 价格太高（¥9800-69800）| 买错了损失太大 |
| 没有试用 | 不知道好不好 |
| 担心电子伤害眼睛 | 潜在风险太大 |
| 品牌不知名 | 没有信任背书 |

**产品启示**：
- **租赁 > 购买**：先每月¥200试试，好用再买
- **免费试用**：7天不满意退款
- **权威认证**：医生推荐、残联采购
- 核心价值主张：**"零风险尝试"**

---

### 痛点4：怕电子设备伤害眼睛（认知偏差）

**用户原话**：
- "屏幕会不会伤害眼睛？"
- "看屏幕不是更累吗？"
- "我看手机一会儿就眼睛疼"

**实际情况**：
- 高对比度屏幕实际上**更护眼**（白化病人需要高对比度）
- 可调亮度 + 滤光片可以解决畏光问题
- 但用户有这个认知偏差

**产品启示**：
- **重新定义电子产品**：不是"伤害眼睛的屏幕"，而是"护眼的显示器"
- 强调**高对比度 > 低对比度**的护眼原理
- 提供**权威医学背书**（眼科医生推荐）
- 核心价值主张：**"比书本还护眼"**

---

### 痛点5：怕改变习惯（惯性）

**用户现状**：
- 望远镜：举着累，但习惯了
- 前排座位：被特殊对待，但习惯了
- 放大镜：手酸，但习惯了
- 同桌念书：麻烦别人，但习惯了

**背后的心理**：
- 改变是痛苦的
- 新产品意味着新的学习成本
- 用户会说"算了，还是老办法吧"

**产品启示**：
- **不要颠覆用户习惯**，而是**渐进替换**
- 望远镜 → 眼镜（外观一样，功能更强）
- 前排座位 → AR眼镜（坐哪都行）
- 核心价值主张：**"不用改变习惯"**

## 三、从用户心理出发的产品方向

### 方向1：课堂伴侣（最直接的"不求人"解决方案）

**用户痛点**：看黑板需要同桌念、举手望远镜很累

**产品形态**：
```
┌─────────────────────────────────────────┐
│              课堂伴侣眼镜                │
│                                         │
│  ┌─────────┐    ┌─────────┐            │
│  │ 摄像头   │ → │ AR显示   │            │
│  │ 对准黑板 │    │ 实时放大 │            │
│  └─────────┘    └─────────┘            │
│                                         │
│  功能只有3个：                           │
│  1. 自动追踪老师写字（不用手动对焦）     │
│  2. 黑板内容放大显示在眼前              │
│  3. OCR朗读（可选）                     │
│                                         │
│  核心价值：                             │
│  ✅ 不需要同桌念了                       │
│  ✅ 不需要举手望远镜了                   │
│  ✅ 坐最后一排也能看清                   │
│                                         │
└─────────────────────────────────────────┘
```

**差异化点**：
- **只做课堂**，不贪多
- **自动追踪**，不用手动操作
- **看起来像普通眼镜**，不引人注目

---

### 方向2：OCR朗读器（"不麻烦别人"的核心功能）

**用户痛点**：高瑞敏看不清但记得住——她最需要的是朗读，不是放大

**产品形态**：
```
┌─────────────────────────────────────────┐
│              OCR朗读器                   │
│                                         │
│  场景1：课堂                           │
│  摄像头对准黑板 → 自动OCR → 语音朗读   │
│  "老师写的是：今天的作业是..."          │
│                                         │
│  场景2：看书                           │
│  摄像头对准书本 → 自动OCR → 语音朗读   │
│                                         │
│  场景3：看手机                         │
│  摄像头对准屏幕 → 自动OCR → 语音朗读   │
│                                         │
│  核心价值：                             │
│  ✅ 不需要同桌念了                       │
│  ✅ 不需要自己看了                       │
│  ✅ 听得懂就能记住                       │
│                                         │
└─────────────────────────────────────────┘
```

**为什么这是核心？**
- 高瑞敏的案例说明：有些用户**看不清但听得懂**
- OCR朗读比放大更重要
- 这是"不麻烦别人"的直接体现

---

### 方向3：看起来正常的眼镜（解决"不想被看出来"）

**用户痛点**：AR眼镜太科技感，会引人注目

**产品形态**：
```
┌─────────────────────────────────────────┐
│              助视眼镜                    │
│                                         │
│  外观 = 普通眼镜                        │
│  功能 = 助视器                           │
│                                         │
│  ┌─────────────────────────────────┐   │
│  │  普通眼镜  │  助视眼镜（看起来一样）│   │
│  │   😎       │      😎              │   │
│  │  ¥200     │     ¥800             │   │
│  │  只能矫正  │    放大+AR显示        │   │
│  └─────────────────────────────────┘   │
│                                         │
│  核心价值：                             │
│  ✅ 没人知道你戴的是助视器               │
│  ✅ 和普通眼镜一样的外观                 │
│  ✅ 和普通眼镜一样的重量                 │
│                                         │
└─────────────────────────────────────────┘
```

**为什么这是差异化？**
- 竞品都在强调"科技感"
- 用户需要的是"正常感"
- 差异化 = **看起来普通**

---

### 方向4：月租订阅（解决"怕花钱买错"）

**用户痛点**：价格太高，不敢一次性购买

**产品形态**：
```
┌─────────────────────────────────────────┐
│              月租订阅                    │
│                                         │
│  ¥200/月 =                              │
│  ├── 设备使用权                         │
│  ├── 软件升级                           │
│  ├── 康复指导                           │
│  └── 故障换新                           │
│                                         │
│  用户感受：                             │
│  - "一个月200，不贵，试试看"            │
│  - "不好用就停，反正没损失"             │
│  - "比买一个¥2000的划算"               │
│                                         │
│  商业价值：                             │
│  - 降低决策门槛                         │
│  - 持续收入                             │
│  - 用户粘性高                           │
│                                         │
└─────────────────────────────────────────┘
```

**为什么这是差异化？**
- 翠鸟的失败 = 一次性收费太高
- 月租 = **零风险尝试**
- 用户先试再买，购买率更高

**用户痛点**：家长担心电子设备伤害眼睛

**产品形态**：

```
│  1️⃣ 眼科医生推荐                        │

│     "这款产品对眼睛是安全的"             │
│                                         │
│  2️⃣ 7天免费试用                         │
│     先拿回家用7天                        │
│     不好用就退                           │
│                                         │
│  3️⃣ 护眼证明                            │
│     低蓝光认证                           │
│     可调亮度+滤光片                      │
│     证明：对眼睛是安全的                 │
│                                         │
│  4️⃣ 康复指导                            │
│     专业康复师指导使用                   │
│     确保正确使用，不伤眼                 │
│                                         │
└─────────────────────────────────────────┘
```

**为什么这是差异化？**
- 翠鸟没做这个 → 家长不敢买
- 我们做这个 → 家长信任度更高
- 核心价值主张：**"医生都说安全"**

## 四、核心结论

### 从用户心理出发的产品设计原则

| 用户心理 | 产品原则 |
|---------|---------|
| 不想麻烦别人 | **"独立"** 而不是 **"帮助"** |
| 不想被看出来 | **"普通"** 而不是 **"科技"** |
| 怕花钱买错 | **"租赁"** 而不是 **"购买"** |
| 怕伤害眼睛 | **"护眼"** 而不是 **"功能"** |
| 怕改变习惯 | **"渐进"** 而不是 **"颠覆"** |

### 产品价值主张重新设计

| 旧版本 | 新版本 |
|-------|-------|
| "帮助盲人看世界" | **"让你自己搞定一切"** |
| "高科技AR眼镜" | **"看起来就是普通眼镜"** |
| "¥3000助视器" | **"每月¥200，先试试"** |
| "AI识别黑科技" | **"比书本还护眼"** |
| "颠覆性的新产品" | **"不用改变习惯"** |

## 五、最推荐的产品方向

### 组合方案：课堂伴侣 + OCR朗读 + 月租订阅

```
┌─────────────────────────────────────────┐
│              课堂助视服务                 │
│                                         │
│  产品 = 眼镜 + App                      │
│  场景 = 课堂 + 看书                      │
│  模式 = 月租订阅                        │
│                                         │
│  ┌─────────────────────────────────┐   │
│  │ 核心功能（只做这两个）           │   │
│  │                                  │   │
│  │ 1. 课堂伴侣                      │   │
│  │    自动追踪黑板 → 放大显示        │   │
│  │    解放双手做笔记                 │   │
│  │                                  │   │
│  │ 2. OCR朗读                       │   │
│  │    摄像头对准 → 语音朗读          │   │
│  │    不需要同桌念了                 │   │
│  └─────────────────────────────────┘   │
│                                         │
│  商业模式 = 月租¥200                    │
│  用户心理 = 零风险尝试                  │
│  差异化 = 只做课堂场景                  │
│                                         │
└─────────────────────────────────────────┘
```

**为什么这个组合是最佳？**

1. **解决最痛的**：课堂看黑板 + OCR朗读 = 最核心痛点
2. **满足心理**：不麻烦别人 + 不被看出来
3. **降低门槛**：月租订阅 = 零风险尝试
4. **差异化**：只做课堂场景，不贪多
