# 社区协作入口与资料流程修订

这是实际技术工作记录，不是会议纪要，不代表社区已通过治理方案。用户在本次工作对话中同意推进；实现和验证由 Codex 辅助完成，社区角色仍待本人确认。

## 本轮工作

- 保留组织 README 品牌、介绍、章节和项目内容，纠正主组织徽标并说明个人需求池与 OpenRare 上游。
- [入口归属表](../../../docs/routing.md)说明社区、项目实现、上游和组织汇总的边界。
- 模板与索引共用元信息，无效记录报错。中文或英文可单独构建。
- 资料状态、来源、主版本和复核人读取实际字段；组织视图与 community 候选看板分开。

## 后续与验收

[协作试行页](../../../docs/pilot.md)保存任务、PR与验证入口。验收包含填模板入库、单语回退、无效字段报错、独立构建及链接检查。不会把未确认的人写成负责人，未读取微信或飞书原文。

## 当前限制

主页修改需有 .github 写权限的维护者应用。发布和接待分工待社区确认；本地网页不承担远端提交或同步。
