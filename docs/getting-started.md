# 找到适合你的第一步

不必先加入组织，也不必先会写代码。你可以从自己熟悉的一小件事开始。

## 我想参与社区建设

先看[社区建设清单](../ROADMAP.md)。文档、导航、内容校对、资料索引和模板试用都需要不同经验。

候选任务正在确认接待安排。找到感兴趣的事项后，可以说明你想做的部分、能投入的方式、希望得到什么帮助。接待人与评审人落实后，再一起确定下一步。

## 我想提出一个需求

从[需求登记说明](needs.md)开始。描述你在什么场景遇到困难、现在怎样处理、希望改善什么即可。不需要先设计完整解决方案。

## 我可以提供支持

从[资源协作](resources.md)开始。导师时间、资料整理、设备、空间、费用、内容或传播协作都可以具体说明。

## 我不熟悉 GitHub

可以先整理成文字或材料，由后续确认的联络人协助登记。当前接待安排见[维护分工](../MAINTAINERS.md)。本地预览可先试填草稿，不会发送到 GitHub。
