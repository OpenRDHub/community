# 1. 导入CT，使用开源工具，进行鼻腔气体建模

### tips

- 结果输出为 (.stl) 格式数据
- 可尝试 mitk 工具
- 鼻腔气体阈值大约为-∞ 到-400
- 注意：输出的stl模型需要排除头部外侧气体，鼻孔处体积和头部外侧空气需要正常切分（右侧画笔的红色区域）
