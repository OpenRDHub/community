# 竞品深度：国内在售助视器型号、价格与渠道

> **调研目的**：为「面向白化病患者的分体式 AR+AI 助视眼镜」项目补齐竞品**真实价格与渠道**数据。
> **目标用户画像**：眼球震颤、畏光、矫正视力 0.1~0.3、需要高倍放大 + OCR 朗读；**价格敏感**，商业模式为**公益 + 残联采购**。
> **数据原则**：价格一律标注来源与时间；无法核实的标「未公开 / 需询价」，**不编造**。

## 0. 核心结论速览

| 维度 | 关键发现 |
|---|---|
| 价格带 | 呈 **三段式**：① 手机+VR 外挂方案 **560~699 元**；② 手持/平板电子助视器 **1358~9180 元**（主流 3000~4600）；③ 头戴 AR/VR 一体助视器 **15999~39800 元**（主流 19800~39800） |
| 渠道 | 三大通路并行：**官网直营 + 微信商城/公众号**、**京东/天猫**、**残联目录 + 政府采购**。头戴高端机几乎不做电商直售，走「门店试戴 + 询价」 |
| 残联采购 | 瑞杰珑（杭州瑞杰珑）、肇观电子（天使眼）已稳定入围多省目录；翠鸟视觉进入**北京市残联平台目录**；度康以「视泰」品牌进入中国残疾人辅助器具中心目录 |
| 白化病适配 | 翠鸟视觉门店预约表**明确列出「白化病」为可选眼病类型**，并支持「眼球震颤」评估——是唯一公开针对该人群做适配登记的国产厂商 |
| 政策窗口 | 民政部《中国康复辅助器具目录（2026年版）》**新增「视力障碍智能辅助设备」类目**；14部门《康复辅助器具产业扩能提质三年行动方案（2026—2028年）》支持智能可穿戴设备纳入目录 → AR 助视眼镜进入残联采购的通道**2026 年正式打开** |
| 价格空白点 | **3399 元的瞳者**（AI 助盲，非放大）与 **560 元的展迈 M1**（手机 VR 外挂）之间，**1500~3000 元「分体式 AR+AI 高倍放大 + OCR」几乎是空白带** |

## 10. 对白化病 AR 眼镜定价与渠道策略的启示

**1. 定价必须锚定「残联补贴上限」而非「竞品零售价」。**
现有数据表明补贴上限集中在 **6000 元**（地市级）与 **12000 元**（深圳市）两档，而瑞杰珑集采实际成交价已达 12300 元。建议设置 **¥5800 / ¥9800 双档 SKU**，让地方残联「补贴即可覆盖」，避免出现「补贴不够、用户自付」的推广阻力；同时零售价可略高（如 ¥6800 / ¥11800）以保护经销商与机构渠道。

**2. 「1500~3000 元」是竞品集体缺席的价格真空，也是最贴合白化病群体的甜蜜点。**
瞳者（¥3399，AI 助盲但**无高倍放大**）、瑞杰珑 Luna S（¥1358，仅 4.3" 屏、19 倍）之间没有「**高倍放大 + OCR 朗读 + 解放双手**」的产品。白化病群体视力 0.1~0.3、有阅读与看远刚需、且价格敏感——**在 ¥2000~3000 档做一款分体式（眼镜轻量 + 处理盒/手机算力）AR 助视眼镜，竞争压力最小、付费意愿最匹配**。分体式恰好能把这档价格做出来（算力外置＝眼镜成本大降，参考度康 CloverAir 的「<80g 眼镜 + <185g 处理盒」思路）。

**3. 眼球震颤与畏光是「必须解决的硬件问题」，也是最好的差异化卖点。**
竞品普遍在此暴露短板：Acesight 有 **Floating Reading Mode（冻结画面）**专为 nystagmus 设计；翠鸟 Aeye-X R4s 的评测明确写「**高倍率下防抖效果不佳**」；度康 CloverAir 主打「**头部跟随 + 专业级智能防抖，高倍下抑制画面抖动**」；白化病群体还有**畏光**刚需——而**低视力滤光镜**在残联目录中是独立品类（90~300 元，几乎人人配发）。建议：① 把**电子防抖/画面冻结**做成核心指标并在白化病社群做实测背书；② **标配可拆卸磁吸遮光罩 + 滤光片**（度康 CloverAir 已有此设计），并争取把滤光功能合并进整机，避免用户分次采购。

**4. 公益组织是最低成本、最高信任度的冷启动渠道，且已被验证可行。**
度康、宜视智能**均已与「月亮孩子之家」（中国白化症公益组织，400 998 2155 / albinism.org.cn）建立优惠合作**；翠鸟视觉的适配预约表**直接列出「白化病」为可选眼病并支持眼球震颤评估**。建议：优先与月亮孩子之家谈「**公益团购价 + 试用征集 + 真实案例共创**」，用 20~50 台种子设备换取白化病人群的适配数据与口碑——这既是后续残联投标的「适配有效性证据」，也是最便宜的获客。

**5. 渠道打法要分层：C 端靠「免费试戴 + 微信私域」，B 端靠「资质 + 门店铺服务网络」，两条腿走路。**
- **C 端**：互联网广告效率低（客单价高、人群窄）。竞品验证的路径是「**官网/公众号留资 → 门店或线上免费试戴 → 客服一对一成交**」（翠鸟 16 城门店、瑞杰珑客服微信 18042451063、度康「度康助视」公众号）。前期可先用**公益组织开展线上试戴 + 视频指导**替代重资产门店。
- **B 端（残联）**：需提前补齐 **医疗器械资质**，采用与零售**分离的集采型号**，并绑定**本地服务商**（残联采购高度依赖本地化交付与售后）；同时抓住 2026 年《康复辅助器具目录（2026年版）》新增「视力障碍智能辅助设备」类目的窗口期，**尽早申报目录准入**，这是进入各省采购清单的前置条件。
