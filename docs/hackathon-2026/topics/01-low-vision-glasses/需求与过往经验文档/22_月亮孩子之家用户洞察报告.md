## 一、人群画像

### 1.1 视力特征（全部文章中最一致的核心事实）

**「几乎所有白化病患者都有视力障碍」**（《白化病特需门诊》《联合国·国际白化病宣传日》）

| 特征 | 具体情况 | 证据 |
|---|---|---|
| 视力谱系 | **普遍 0.01 ~ 0.2**，少数 0.3；个体差异极大 | 0.01（高瑞敏，2025-09-21）、0.1（汤雅玲/刘吟/盛小康/吴教授）、0.12 伴内斜+眼震（狄小水术前）、0.2 上下（狄小水日常）、不足 0.3（莹姐）、视力残疾四级仅微弱视物（胡明耀）、三级残疾（陈丁） |
| 眼球震颤 | 高频伴发，直接决定助视器可用性 | 「严重眼球震颤会影响观察目镜进而影响助视效果」（Aeye-T 04 评测）；狄小水做过眼震手术；10%~20% 需手术矫正斜视/重度眼震（希玛门诊） |
| 畏光 | 群体标志，「即使闭上眼也不足以避免不适」 | 游泳半小时二级烫伤（刘吟）；舞台强光下「眼睛眯成一条缝」（奇迹）；「喜欢夜晚出行、聚会」是群体行为特征 |
| 戴镜矫正 | **多数戴镜效果差且不适**，仅轻症有效 | 「矫正后仅相当于近视 800 度水平且戴镜不舒服」（高瑞敏）；「配眼镜效果不理想仍一戴几十年」（赵瑞）；黄芹「自幼戴眼镜很好地改善了视力」（轻症反例） |
| 并发症 | 卷丝状角膜炎、斜弱视、黄斑中心凹发育不良 | 狄小水（绷带镜治疗）、希玛门诊、华西基因治疗文 |
| 干预窗口 | **3 岁内正确干预一般可获得正常有效生活视力** | 希玛特需门诊；莫爸自制视觉刺激视频（0-3 岁） |

### 1.2 人口与社会经济数据（中国罕见病联盟 2019 调研，确诊患者 444 人，2020-06-13 文全录）

- **年龄**：平均 11.34 岁（未成年人 335 / 成年人 109）——**儿童是绝对主体，家长是购买决策人**
- **患病率**：约 1/17000，推算全国 **9~11 万人**
- **成年患者收入**：个人年收入均值 **34,239 元**
- **就业**：约 70% 就业、23% 未就业；未就业者中 **90% 归因于白化病**；全职仅占一半
- **辅具支出**：2018 年度户均 1,554 元，其中 **自费 1,444 元（自费率 93%）**——辅具几乎无保障覆盖
- **辅具依赖度**：16.5% 完全不需要、6.4% 完全离不开——中段 77% 是「有需要但可勉强代偿」的弹性市场
- **心理健康**：「有一点焦虑或沮丧」高达 **46.19%**
- **信息渠道**：微信公众号/微博 + 病友组织是第一信息来源——**社群即渠道**

### 1.3 心理与身份认同

- **病耻感是贯穿一生的暗线**：外号清单几乎人人有份——「白血病」「白素素」「白眉鹰王」「白毛女」「雪里谜」「白眉大侠」「小白孩」「妖怪」「怪物」；6 岁被对方家长当面拉走孩子：「谁让你跟这个妖怪玩的，走！回家！」（《童话里不是骗人的》）
- **遮掩行为**：每月染发持续十余年（苏悦）、染发二十多年（周东东）、「摸着被染黑的头发哭泣」（兰池莲）
- **抑郁真实存在**：狄小水确诊重度抑郁症；求助心理医生被母亲回绝「脑子有病的人才去看心理医生」
- **最高诉求是「被当普通人对待」**（8 位自述者中 4 位原话）：
  - 「我希望大家以对待普通人的方式来对待我」（周峰毅）
  - 「不要对我大惊小怪，不要特别照顾我……像见到普通人一样回应就好了」（半个西瓜）
- **接纳叙事成熟**：「白化病就像一颗痣，无关痛痒的一颗痣」（兰池莲）；「当你自己不在意的时候你会发现大家也没那么在意你」（赵瑞）——产品文案应避免「残缺叙事」，用「生来闪耀」式表达

## 二、现存问题（按场景）

### 2.1 教育（最高频，约 1/3 文章直接涉及）

- **看黑板是头号困难**：从 2016 到 2025 跨越九年的文章反复出现同一句话——
  - 「即便坐在教室第一排也看不清黑板粉笔字」（王乐群，2016）
  - 「即使坐在第一排，黑板上的字也看不清，即使是很大的字体，只要稍稍反光，也是没办法看清的」（狄小水，2019）
  - 「一节数学课，黑板被擦了又写，写了又擦，如此四五次，我根本就跟不上老师的进度」（狄小水）
  - 「十二年坐第一排也没有一天能看清黑板上的字，全靠抄同桌的笔记」（赵瑞，12 年贯穿）
  - 「第一排紧挨讲桌仍看不清黑板，靠同桌逐句读黑板内容上学」（高瑞敏，2025）
- **近距离阅读疲劳直接改写人生路径**：「初三课业繁重，长时间近距离用眼造成频繁头痛，无奈放弃了梦寐以求的重点高中」（刘吟）；狄小水高考比模拟低 50 多分只能读二本
- **被误读为态度问题**：「每当我遇到困难时，人们总觉得是我不愿意努力造成的」（刘莹）；孩子把「看不清导致的学习遗漏」内化为「我很笨」
- **制度性障碍**：教师资格证体检被卡（小静维权 2 个月、跑医院 30+ 次）；高考体检被告知不能报法律专业（周峰毅）；常规产检无白化病基因筛查（奇迹母亲）
- **已有解法可借用**：中考高考可申请大字卷/延时（需残疾证）；高考合理便利（蒋志恒：佩戴机械表进考场）

### 2.2 就业

- 面试歧视高频且不可明说：「面试官都很客气地说我各方面都很优秀，让我回家等通知」（高瑞敏，毕业 3 年待业）；「很多面试官打量我一下，问一两个问题就说让我回去等电话」（刘吟）
- 岗位受视力+外观双重限制：缝纫工「做时间长了眼睛受不了」放弃；「好多客人不要我服务，说看到我的皮肤觉得害怕」（按摩师燕子）
- 成功案例集中在：程序员（读屏）、教育培训、机械加工（赵瑞）、IT 运维（陈丁，国际残障技能大赛银牌）、文案策划、美业、音乐——**共同点：远距/听觉/技能型，而非近距密集文书**

### 2.3 出行

- 认人困难是独有痛点：「走在路上我连爸爸从我身边走过我都不会认出他，所以请发出声音我才有可能知道你是谁」（汤雅玲）；「与人交谈时眼睛总会不由自主地四处瞟，或者歪着头……它没有加载人脸识别功能，但没关系，我还有声音识别功能」（白介）
- 看站牌/红绿灯/列车座位号需望远镜；多重残障者无人陪同无法出行（毛艳芳）
- 夜间是舒适时段：「只有在月光下，我们缺乏黑色素的眼睛才能舒服」（王乐群）

### 2.4 社交与歧视

- 被围观、被疑传染而躲开、被问「是不是外国人/染发了吗/会遗传吗」是日常背景音
- 家长连带受辱是最痛刺激源：「你这个没本事的人，生出个妖怪一样的丫头」；有家长让自己孩子「离她远点儿」
- 婚恋歧视：对方家庭因遗传顾虑反对；「我吃过的苦，我的女儿还会再吃一次吗？」（燕子）

### 2.5 医疗

- 「白化病通常被归为皮肤科治疗范畴，白化病眼病一直未受重视，『无医可治』造成部分孩子永久性视力障碍」（上海希玛门诊文）
- 信息不对称催生偏方史：晒太阳疗法、发色偏方、病急乱投医
- 已形成口碑就医网络：北京同仁（魏爱华团队/基因）、301（验光配镜）、希玛系白化病特需门诊（深圳/上海）、山东亮康（眼震手术）；**2026-04 华西完成全球首例 OCA1 眼科基因治疗（JWK010）**，但 I/II 期临床周期内（至 2030 年前后）助视需求刚性不变

## 三、需求痛点分级

### P0（不解决就不买）

| 痛点 | 证据强度 | 说明 |
|---|---|---|
| **看黑板（远距放大）** | 9 年跨度 10+ 篇反复出现 | 第一排无效 → 光学/电子远距方案是刚需核心 |
| **近距阅读防疲劳** | 「频繁头痛→弃重点高中」 | 痛点是「疲劳+效率」而非单纯看不清；护眼（蓝光/亮度/闪烁）是硬指标 |
| **外观不像辅具（防病耻感）** | 3 篇独立原话 | 「戴上就像宇航员所以她不喜欢这款**很好用的**头戴式电子助视器」（莫莫）；「察觉有人在看就 Alt+F4 关掉放大镜」（程序员）；平板方案因「看起来只是用平板」而成功——**外观决定产品生死，功能其次** |
| **价格可负担** | 「数千到上万元一般家庭难以承担」 | DIY 2,630 元、展迈 M1 699 元是社群认可锚点；组织常态为患者砍价（8 折/专属券）；辅具自费率 93%、户均年支出仅 1,554 元 |

### P1（强烈渴望，现有方案全都有缺陷）

| 痛点 | 现状 |
|---|---|
| **OCR 朗读且必须离线** | 天使眼（3,800 元）离线但竖排/分栏/形近字全错、续航 1 小时；Luna 8 因「无语音识读」被判不适配部分人群；两篇文章点名离线能力 |
| **看黑板 + 低头写字无缝切换** | 单筒望远镜需「不停翻转/手动对焦/一直举手」；Aeye-P4 双屏远近同看是方向但有延迟，「书写比较影响体验」 |
| **轻便、能戴着走** | 璧羽「重、颈椎压力、不便携」；Acesight 系列「体积稍大」；「低视力朋友们最大的愿望就是能够更加轻便和易操作，如果能做到像普通眼镜那样最好」（评测原话） |
| **眼震兼容** | 眼震直接影响目镜观察和画面稳定——现有产品几乎无一正面解决 |
| **畏光适配** | AR 投影「强光下可视性大打折扣」；亮度/滤光是用户第一步操作；墨镜夹片有专文选购指南 |

### P2（惊喜项/差异化机会）

- **人脸识别+语音提示**：社群自己已经在想象这个功能（「它没有加载人脸识别功能，但没关系，我还有声音识别功能」）；评测文章展望的四大 AI 功能——**实景导航、障碍物/台阶提醒、人脸识别提示、远程协助**——与本项目方向完全重合
- **夜间增强模式**：群体「喜欢夜晚出行」是未被任何产品覆盖的场景
- **电脑/手机投屏联动**：R4s 电脑投屏被评「极大提升工作效率」但缺 Windows 支持
- **大字试卷/教材配套**：「如果能有大字版的教材，如果老师能边板书边读出内容」（刘莹的三个「如果」）

## 四、现有替代方案全景（他们现在怎么办）

### 4.1 无辅具代偿（最大「竞品」，零成本）

| 方案 | 使用者 | 局限 |
|---|---|---|
| 坐第一排 | 几乎所有人 | 「第一排也看不清」——被 9 年的文章证伪 |
| **靠听 + 借同桌笔记** | 盛小康（国奖+港城大读研）、赵瑞（12 年）、高瑞敏、蒋志恒 | 完全依赖他人配合；「好的同桌是月亮孩子的高配」但不可复制 |
| 手机拍照放大 | 兰池莲、李雪、莫莫父母 | 静态、操作繁琐、 classroom 场景跟不上 |
| 放大复印件（琴谱 A4→8 开、乐谱复印放大） | 盛小康、家长 | 静态、费家长精力 |
| 电脑放大镜/读屏软件 | 程序媛（NVDA+争渡）、兰池莲 | 卡顿、无障碍差的网页无能为力 |
| 放弃/降级 | 刘吟弃重点高中、狄小水高考失利 | **最普遍的「方案」：因工具不足而牺牲上限** |

### 4.2 光学助视器（入门首选，「便宜、简单」但体验差）

| 方案 | 价格线索 | 用户真实评价 |
|---|---|---|
| 手持放大镜（2~10 倍） | 便宜 | 「普通的放大镜也不足以看清」；占用双手；被老师当玩具 |
| **单筒望远镜/观察镜（4~10 倍）** | 便宜，可挂颈 | 看黑板最常用；但「视野小、不停移动镜头、不同距离手动对焦、手一直举着」四宗罪；DIY 平板失败后它仍是默认方案——**惯性之选，不是满意之选** |
| 眼镜式近用助视器（4D~32D） | 便宜 | 莫莫家两副「几乎都是废弃不用的，宁可把书拿近」——沉、麻烦 |
| 眼镜夹式望远镜 | — | 越放大视野越小；需翻转切换；孩子难掌握 |
| **OCUTECH VES SPORT-II**（美产头戴光学，23g） | 美元代购 | 吴教授用了 12 年：「写文章、备课、看手机都离不开」；但需训练、视野小靠转头补偿、当年「用美元从美国购买」渠道艰难 |
| 翠鸟 Aeye-T 04（50g 眼镜式光学） | ¥19,800（见[[竞品深度_国内在售与渠道]]） | 解放双手、看黑板+下方写字；**目镜小需适应、严重眼震影响使用、多次反射画面偏暗畏光者户外难用** |
| 墨镜夹片/偏光镜 | 低 | 刚需配件，社群反复批量发放 |

### 4.4 头戴式电子助视器（与本项目直接对标）

| 型号 | 价格 | 优点 | 缺点/结局 |
|---|---|---|---|
| 展迈 S1（VR+手机） | 未标 | 相当于 3 米看 85 寸屏、透明镜片可行走 | 适配手机极少、<0.05 视力吃力、**强光下投影不可视（畏光硬伤）**、不适合中学生以下 |
| 翠鸟璧羽（VR 一体） | 「略显偏高」 | 1-20 倍、快速局部放大「非常实用」、几乎不漏光 | **重/颈椎压力/未成年人无法用**；<2 倍黑边、>10 倍清晰度不足、暗光噪点 |
| 瑞杰珑 Acesight VR | 未标 | 16X、冻屏、流畅度出众 | 无 OCR；「市场上头戴式没有大家期盼的那么**轻便**与**经济**」 |
| 瑞杰珑 Acesight AR | 未标 | 15 倍、轮廓模式、画面悬停、可戴着走 | 体积稍大（技术代际旧）；评测展望导航/避障/人脸识别——**社群原生的需求清单** |
| 翠鸟 Aeye-X R4s（AR+外置计算单元） | ¥39,800（零售价，见竞品文件） | **较轻便可长戴**、离线 OCR、陀螺仪翻页、屏幕下方透明区可行走、磁吸屈光镜片 | 价格极高；电脑投屏缺 Windows |
| 展迈 M1（VR+手机+APP） | **699（月亮孩子 560）** | 「几百元+自己的手机≈一两万元头戴效果」；OCR 朗读、冻屏 | VR 形态外观、依赖手机 |

### 4.5 人力与环境支持

- 同桌读题/借笔记、老师口述板书、父母拍照放大、残联/病友组织免费发放（2018 年 160 人、2019 年 141 人，内容为偏光镜+光学放大镜/望远镜）、希玛公益手术名额——**公益供给是重要渠道但完全无法覆盖需求**

### 4.6 用户选择规律（莫爸十年验配经验总结，全库最有价值的方法论）

> **好用 + 方便 + 孩子自愿，缺一不可。**

1. 平板式电子助视器最成功——因为同学觉得「潮」、不奇怪、不影响社交
2. 头戴式功能再好，因「像宇航员」被拒——**外观社会化 > 功能**
3. 眼镜式只适合「视力极差且年龄较大、心理能接受」的孩子
4. 「随着科技发展，替代助视器的方法也会随之改变」——父母直接拍照给她看

## 五、给产品的十条结论（全部有原文依据）

1. **远距看黑板 + 近距防疲劳书写**是证据最硬的双核心场景；现有光学方案「四宗罪」（视野小/手动对焦/手举着/翻转切换）就是产品验收标准。
2. **外观是生死线**：目标形态必须「看起来像一副普通墨镜/太阳镜」——这恰好与畏光人群日常佩戴墨镜的习惯天然融合（戴墨镜出门对这个群体是常态，不引人注目）。
3. **OCR 朗读必须离线**，并把天使眼评测的缺陷清单（竖排/分栏/形近字/标题漏读/单一音色/续航）当作现成验收清单。
4. **人脸识别+语音提示**是社群自己喊出来的需求，传统助视器结构性空白，是 AR+AI 的独占卖点。
5. **眼震与畏光是白化病特异约束**：通用低视力产品不解决；画面防抖、亮度自适应、户外投影可用性要在硬件层定点突破。
6. **定价锚点**：DIY 2,630 元 < 天使眼 3,800 ≈ Luna 8 券后 4,198 < 璧羽/R4s（1~4 万）。结合残联补贴上限（地市 6,000/深圳 12,000，见竞品文件），**主力 SKU 落在 6,000 元内**是社群心理与补贴政策的交集。
7. **渠道即社群**：月亮孩子之家常态组织团购砍价与辅具发放（年均 140~160 人），信息获取第一渠道就是病友组织——进社群 = 进渠道；北京聚茂源、成都爱尔、希玛系门诊是既有验配网络。
8. **儿童是主体用户**（调研平均 11.34 岁），但未成年人的外观敏感度最高、课桌空间和换座位是教室三大工程约束（悬臂支架、超广角、座位无关性设计）。
9. **家长是付费决策人**，其行为特征：病急乱投医史、对「3 岁干预期」焦虑、依赖病友组织口碑——营销应打「权威医生背书 + 社群真实案例」，禁用残缺叙事。
10. **时间窗口**：华西基因治疗 2030 年前后才可能落地，且 OCA1 仅占部分分型——**未来 3~5 年助视刚需不变**，正好覆盖产品从验证到成熟的全周期。
