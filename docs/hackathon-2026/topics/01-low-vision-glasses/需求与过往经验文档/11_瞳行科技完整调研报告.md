## 二、产品体系：瞳者

瞳行科技的产品是一套**完整的智能导盲解决方案**，包含四个核心组件：

### 2.1 产品架构图

```
┌─────────────────────────────────────────────────────┐
│                    瞳者 AI助盲系统                    │
├─────────────────────────────────────────────────────┤
│                                                     │
│  ┌─────────┐  ┌─────────┐  ┌─────────┐  ┌───────┐│
│  │  AI眼镜 │  │蓝牙戒指 │  │  盲杖   │  │专用手机││
│  │ (主体)  │  │ (遥控)  │  │ (触觉)  │  │(处理)  ││
│  └─────────┘  └─────────┘  └─────────┘  └───────┘│
│                                                     │

└─────────────────────────────────────────────────────┘
```

### 2.2 产品1：AI眼镜（核心主体）

| 参数 | 规格 |
|------|------|
| **摄像头** | 121度超广角双摄 |
| **显示** | 骨传导 + 开放式耳机 |
| **重量** | 轻量化设计 |
| **功能** | 视觉感知、环境理解 |
| **技术** | 通义千问Qwen-VL + OCR |

**技术特点**：
- 自研视觉AI模型
- 深度学习算法处理摄像头输入
- 图像实例分割
- 视觉大模型集成

### 2.3 产品2：蓝牙戒指

| 参数 | 说明 |
|------|------|
| **功能** | 遥控控制 |
| **用途** | 操作眼镜、触发功能 |
| **交互** | 手指操作，无需语音 |

**使用场景**：
- 快速触发识别
- 切换功能模式
- 紧急求助

### 2.4 产品3：智能盲杖

| 参数 | 说明 |
|------|------|
| **功能** | 触觉反馈 |
| **技术** | 智能感知 |
| **协同** | 与眼镜配合使用 |

**特点**：
- 不是替代传统盲杖
- 而是智能增强版
- 提供触觉+听觉双通道反馈

### 2.5 产品4：专用手机

| 参数 | 说明 |
|------|------|
| **角色** | 数据处理中心 |
| **功能** | AI计算、显示、通讯 |
| **系统** | 基于通义千问 |

**技术架构**：
- 边缘计算 + 云端协同
- 本地实时处理
- 云端深度分析

| 维度 | 瞳行科技 | 我们的机会 |
