# 02｜这不是一场传统黑客松

![这张图片是“罕见·无界”黑客松相关的内容页面，核心是表明举办者的理念：想做的不只是传统黑客松，目标是解决真实问题、让项目可持续生长。页面明确说明比赛虽有终点，但参赛完成的开源项目可继续迭代优化，同时列出了该黑客松的核心特点，包括赛题源于真实患者、患者是共创者、赛题是持续开放的开源项目，还强调不要求参赛者都创业，也不强制做出“大而全”的产品，真实、有用、可验证的小功能同样值得认真完成。](https://feishu.cn/file/USUJblDzGoP7obxdXKDcDfBhnhd)

本次黑客松有几个重要特点：

- 所有赛题均来自真实患者和真实生活场景；
- 患者不是“被帮助者”，而是项目共创者；
- 一个赛题就是一个持续开放的开源项目；
- 可以一个人参赛，也可以多人组队；
- 同一道赛题可以同时存在多支队伍、多个方案；
- 赛前不做强制孵化，但提前开放患者、疾病知识、导师、AI 与技术资源；
- 线下重点不仅是开发，还包括真实测试、资源链接与合作；
- 无论比赛结果如何，项目成果都需要完成开源；
- 比赛结束后，有价值的项目可以继续由原团队或新贡献者接力。

# 05 ｜ 开源，是参赛前提

![图片展示了开源项目的基本要求，以GitHub为项目协作入口，持续更新README、Issues、文档与版本；不只公开代码，可公开设计、BOM、测试过程和失败经验；尊重原创与贡献，记录来源、贡献、署名，商业化明确合作安排；允许多人、多路线、长期接力，不因比赛或某支团队结束而归零。这些要求与文档中关于参赛前提的阐述相呼应，强调开源项目需在比赛结束前完成成果整理与上传，包括需求与背景资料、方案设计等多方面内容。](https://feishu.cn/file/QCJSbsT7IogDgBxJZsicWxFQnvg)

## 基本要求

无论：

- 是否获奖；
- 是否完成全部功能；
- 是否赛后继续；
- 是否未来进行商业化；

比赛期间产生的可公开成果，都需要在赛事结束前完成整理与上传。

包括但不限于：

- README / 项目说明；
- 需求与背景资料；
- 方案设计；
- 研究与技术探索记录；
- 源代码；
- CAD / 3D 模型；
- 硬件设计；
- BOM；
- 测试记录；
- 失败尝试与经验；
- 使用说明；
- 后续 Roadmap。

## 特别说明

患者隐私、医疗数据、个人身份信息、未经授权的医学资料等，不属于“必须公开”的内容。

**开源不等于公开患者隐私。**

涉及敏感信息时，以患者授权、隐私保护和安全为第一原则。

# 11｜如何与患者协作？

患者是本次赛事的重要共创者，即为赛手团队成员之一：患者参与&贡献如下：

**第一层：公共患者资料，所有赛手共享：**

- 需求介绍；
- FAQ；
- 患者资料；
- 已有场景和反馈。

**第二层：具体问题确认**

如果团队在推进过程中产生具体问题，可以提交给患者确认。

**第三层：深度共创 / 测试**

当团队已经有：

- 明确方案；
- 核心假设；
- 原型；
- 可测试功能；

可以进一步安排患者深度交流或测试。

原则是：

> **不要用患者时间替代赛手自己的研究。**

能通过已有资料、AI、技术研究解决的问题，尽量先自行完成。

真正需要患者判断的问题，再进入患者共创。

# 12｜比赛结束以后怎么办？

## 原团队愿意继续

原团队可以成为长期社区共建者。我们会根据项目情况继续提供：

- 患者连接；
- 开源运营；
- 技术辅导；
- 测试；
- 产业资源；
- 设备；
- 商业化；
- 投资连接。

## 原团队不再继续

没有关系，我们尊重每一位赛手的选择；但Khub将视赛题情况，继续寻找新的开源力量持续迭代开源作品，直至解决患者问题

## 原团队希望独立发展 / 商业化

可以。在遵守开源协议的前提下，团队可以继续：

- 创业；
- 融资；
- 开发商业产品；
- 与企业合作。

**与此同时，社区仍然继续维护公共开源版本，同时为团队提供商业化、市场化资源支持**

## 同一个项目同时有多个团队继续

也可以，Khub 支持的不是“唯一官方团队”。

而是：

> **真正愿意继续推进，并让成果服务患者与社区的人。**

# 15｜常见Q&A

### 可以只参加线上吗？或者只参加线下吗？

- **可以只参加线上**：欢迎以开源贡献者的身份参与线上共创；但若团队无人参与线下部分，则不计入黑客松比赛范围。
- **推荐线上 + 线下结合**：参与线上开源贡献的团队，至少 1 名成员参与线下黑客松——除了冲击奖金，现场还有更多面对面的讨论与连接。
- **不建议只参加线下**：仅靠线下 3 天，难以真正解决罕见病患者的问题，对患者的需求也不够了解；先在线上进入项目，线下才有真正的产出。

### Token 等资源如何发放？

Token、算力等支持资源按项目进展分三批发放，项目走得越远，能拿到的支持越多：

- 第一波：线上共创期，提交产品方案后发放；（由组长统一申请&发放，请提前完成组队）
- 第二波：交付部分技术进度后发放；
- 第三波：线下现场发放。
