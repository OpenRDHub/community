# 资源与支持

把能够提供的支持和希望获得的帮助说具体，便于找到合适的协作对象。

## 登记入口

已有 community 权限者可[使用资源协作模板](https://github.com/OpenRDHub/community/issues/new?template=resource.md)，同时说明是提供支持还是申请支持，并注明尚待确认的条件。已有资源事项请在[原 Issue](https://github.com/OpenRDHub/community/issues)补充。

没有仓库权限时，可先准备“支持内容、条件、可用时间、希望的合作方式”四项信息，通过已认识的社区联络人或已有微信群协助对接。统一对外资源接待入口尚未落实，登记也不代表资源已获确认或承诺兑现。

## 可以提供什么

一次审阅或答疑、资料整理、设备与制作条件、场地、费用，以及内容或传播协作，都可以说明适用范围与时间。

登记时写清：支持内容、提供条件、额度或可用时间、有效期与后续对接方式。私人联系方式不要放进公开记录。

## 当前资源状态

本版尚未录入经提供方确认的资源，因此没有可领取的导师时段、设备额度、报销或岗位承诺。

后续目录区分“正在征集”“已确认可提供”和“已分配或兑现”，记录最近确认时间与实际用途。

## 如果你需要支持

说明正在做什么、具体缺什么、希望如何使用，以及能留下什么使用或成果反馈。稀缺资源的分配依据事先说明，相关决定留下记录。

## 怎样认可支持

按双方约定记录贡献、使用反馈和成果展示。署名与个人信息由本人决定是否公开；赞助不自动带来全部社区事务的决定权。
