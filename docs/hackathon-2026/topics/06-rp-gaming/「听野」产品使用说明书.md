# 「听野」产品使用说明书

**听野（SenseField）安装与使用说明**  
本文以2026年10月1日的安装包及vivo手机界面为例；不同版本、机型的页面名称可能略有差异。

目前仅限安卓，并无适配苹果。

**第一步：下载安装包**

两种方式选其一。

**第二步：进入权限设置**  
打开“听野”，在“选择辅助游戏”页面点击“王者荣耀”的“开始辅助”；进入“王者荣耀辅助”页面后，依次点击“设置”和“授权与运行设置”。

**第三步：设置运行权限**  
在“授权与运行设置”页面依次检查运行通知、置顶视觉提示和后台省电策略。以下以 vivo 手机为例，其他机型请查找相近的系统设置项。  

![图片展示了vivo手机“授权与运行设置”页面中运行通知和置顶视觉提示的相关设置。其中，运行通知已允许，下方有“授权运行通知”按钮；置顶视觉提示已允许，勾选了“允许使用视觉提示”，并有“授权置顶显示”按钮。该图片与上文设置运行权限的内容相关，直观呈现了vivo手机在运行通知和置顶视觉提示方面的操作步骤，帮助用户在“听野”产品使用中完成相应权限设置。](https://feishu.cn/file/MsvXbTZDfo46Tbxlb7Sc8KounPb)

运行通知：点击“授权运行通知”，在跳转的系统页面为“听野”开启“允许通知”。  

![图片展示的是vivo手机“听野”应用的运行通知设置界面。界面上方显示“听野”标题，下方有“允许通知”开关，已开启（红框突出显示）。下方“接受智能通知控制”处，智能通知和功能开启后，将根据通知重要等级定义提醒方式。提醒方式有“悬浮通知”和“锁屏通知”，二者均被勾选（红框突出显示）。该图片与上文“运行通知：点击‘授权运行通知’，在跳转的系统页面为‘听野’开启‘允许通知’”的内容对应，直观呈现了开启允许通知的操作结果。](https://feishu.cn/file/BpBBbkpqZo0ythxj1WMcsVIgnvd)

置顶视觉提示：如需使用此功能，勾选“允许使用视觉提示”，点击“授权置顶显示”，再在系统悬浮窗应用列表中找到“听野”并开启权限。请避免提示遮挡游戏画面。

![图片展示的是vivo手机系统悬浮窗应用列表界面。画面中“听野”应用被红色框和箭头突出显示，其右侧开关处于开启状态。该图片与文档中“置顶视觉提示”设置步骤相关，用于说明在系统悬浮窗应用列表中找到“听野”并开启权限的操作，以确保“听野”应用在使用时能有置顶视觉提示功能。](https://feishu.cn/file/XRzXbjRpwoR0fcxA4bHcsy1BnYd)

后台省电策略：点击“系统省电优化设置”，在系统应用列表中选择“听野”，设置为“允许后台高耗电”，以减少后台运行时被系统停止的情况。

**第四步：测试与调整提醒**  
返回“王者荣耀辅助”页面，打开“配置与调参”。点击“测试提醒”和“测试震动”，确认语音与振动正常；如需调整播报效果，可选择语音引擎并调节语速。

![图片展示的是“王者荣耀辅助”中“配置与调参”页面。页面上方显示“听野 王者荣耀”及“配置与调参”标题。下方“提醒测试与语音”区域有“选择语音引擎”“语速：1.6倍”“测试提醒”“测试震动”选项。底部“标定配置”区域有“导入配置文件”选项。该图片与文档中“第四步：测试与调整提醒”内容对应，用于指导用户在“王者荣耀辅助”中进行测试提醒和调整语音语速等操作。](https://feishu.cn/file/F2iXbx6sRoEDVvxBVz5cOCxWnHh)

**第五步：启动或停止辅助**  
确认设置无误后，返回“王者荣耀辅助”页面点击“开始”，让app录制屏幕后即可打开王者荣耀；  
结束使用时点击“停止”。若没有收到提醒，请检查通知权限、系统音量及省电设置。
